## 本番にする手順

### ① 音声を VOICEVOX に差し替える

```bash
# VOICEVOX を起動しておく(エンジンが localhost:50021 で待ち受ける)
python3 voicevox_audio.py ../台本/01_披露宴_定食屋の親.md out_audio/
```

カードごとの wav と `timing.json` が出ます。話者IDはバージョンで変わるので
埋め込まず、起動中のエンジンの `/speakers` から**話者名+スタイル名で毎回引き直し**ます。

配役:

| 役 | 話者 / スタイル | 話速 | 音高 | 抑揚 |
|---|---|---|---|---|
| 結衣(主人公) | 九州そら / ノーマル | 1.05 | 0.00 | **0.90** |
| 政子(義母) | WhiteCUL / たのしい | 1.10 | +0.03 | **1.15** |
| 涼介(婚約者) | 青山龍星 / ノーマル | 1.00 | 0.00 | 0.95 |
| 健一(父) | 玄野武宏 / ノーマル | 0.92 | -0.02 | 0.90 |
| 鷹野(会長) | 玄野武宏 / ノーマル | **0.88** | **-0.04** | 0.85 |
| 黒田・プランナー・親族 | 白上虎太郎 / ふつう | 1.00 | 0.00 | 1.00 |

父と会長は同じ話者なので、**話速を0.04以上離して**聴き分けさせています。

「そこで初めて、私は泣きました。」の1行だけ、抑揚を `0.90 → 1.05`、
話速を `1.05 → 0.95` に自動で切り替えます。全編で感情を殺してきた声が、ここだけ揺れる。

> **辞書登録を先にやってください。** 人名6語(中村結衣・中村健一・神崎涼介・
> 神崎政子・鷹野誠一・鷹野物産)を登録しないと、アクセント句が割れて棒読みになります。
> 詳細は `../台本/00_VOICEVOX読み辞書.md`。

### ② 絵を作る

各カードの「ここに入る絵」が作画指示です。ト書きはシーン単位なので、
1シーンにつき1〜2枚描けば足ります(全16シーン)。

### ③ 組み直す

```bash
python3 make_video.py ../台本/01_披露宴_定食屋の親.md out.mp4
```

`make_video.py` の `CAST` と `render()` を差し替えれば、同じ尺で本番が組めます。

## 音声素材のライセンス

`voices/` は MMDAgent Example の HTS音声(mei / takumi)。
修正BSDライセンスで、**商用利用可・クレジット表記が必要**です。
`voices/mei/COPYRIGHT.txt` と `voices/takumi/COPYRIGHT.txt` を必ず読んでください。

ただし**本番はVOICEVOXに差し替える前提**なので、これらは絵コンテ用です。
VOICEVOXを使う場合のクレジットは概要欄の `音声:VOICEVOX` に加え、
利用する話者ごとの規約を確認してください。
