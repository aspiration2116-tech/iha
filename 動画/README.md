# 動画

台本 v17(先生の最終採点 96点「録れ」)から本番動画を作るための一式です。

| ファイル | 役割 |
|---|---|
| `lovart_プロンプト集.md` | **Lovartに貼るプロンプト。キャラ設定シート5枚 + 場所3枚 + カット46枚(推奨58枚)** |
| `gen_prompts.py` | 台本からプロンプト集を再生成する。台本を直したら必ず実行 |
| `compose_final.py` | 絵 + テロップ + 音声 → 本番動画 |
| `voicevox_audio.py` | 台本 → VOICEVOXのwav + `timing.json` |
| `make_video.py` | 旧・絵コンテ専用(残してあるだけ。通常は `compose_final.py` を使う) |
| `images/` | ここに `cut01.png` … を入れる |

---

## 手順

### ① 絵を作る(Lovart)

`lovart_プロンプト集.md` を上から順に。**キャラクター設定シートを先に5枚**作って、
以降のカットで参照画像として毎回添えてください。これをやらないと毎カット別人になります。

保存先と名前:

```
動画/images/cut01.png
動画/images/cut02.png
   …
動画/images/cut46.png
```

長い場面は2枚目を足せます。`cut10b.png` のように `b` `c` を付けると、
その場面の中で自動的に切り替わります。**足りない番号は仮画像が入るだけなので、
1枚も無くても動画は組めます**(尺とテロップの確認用)。

画面比は **16:9 / 1920×1080**。違う比率だと組むときに切れます。

### ② 音声を作る(VOICEVOX)

先に**人名6語の辞書登録**をしてください(`../台本/00_VOICEVOX読み辞書.md`)。
登録しないとアクセント句が割れて棒読みになります。

```bash
# VOICEVOX を起動しておく(localhost:50021)
python3 voicevox_audio.py ../台本/01_披露宴_定食屋の親.md out_audio/
```

配役・話速・抑揚は `../台本/00_VOICEVOX読み辞書.md` の話者表のとおりです。
父と鷹野は同じ話者なので、話速を0.04以上離して聴き分けさせています。

### ③ 組む

```bash
python3 compose_final.py
```

既定で `../台本/01_披露宴_定食屋の親.md` + `images/` + `out_audio/` を読み、
`披露宴_定食屋の親_本番.mp4` を書きます。パスを変えるなら:

```bash
python3 compose_final.py --script ../台本/01_披露宴_定食屋の親.md \
                         --images images --audio out_audio --out 本番.mp4
```

`out_audio/timing.json` が無ければ open_jtalk で仮の音声を作るので、
**VOICEVOXが無い環境でも尺とテロップの確認はできます**。

---

## compose_final.py が自動でやること

- **絵をゆっくり動かす**(Ken Burns)。静止画のままだと紙芝居になり、離脱します。
  寄る/引くと寄る位置は場面番号で交互に散らします。
- **テロップを絵の上に重ねる**。下半分を暗く落として文字を読ませます。
  改行は台本のまま。1行18字以内・1カード2行以内は台本側で保証済み。
- **話者名を出す**。ただし主人公(結衣)の地の文には出しません。
- **無音を実尺で入れる**。`【無音1.2秒】` は絵をそのままに1.2秒止めます。
- **音声の実尺に合わせる**。1カードごとに測って、語尾に0.22秒の余韻を足します。

## 収録前の確認

1. **尺を実測する。** 台本の推定は20分37秒ですが、VOICEVOXの間(ま)で十秒単位ずれます。
   `compose_final.py` の最後に出る実測値が **20:40を越えたら**、
   `../台本/09_先生の最終採点.md` の6章の表にある「−」の行から順に切ってください。
2. **辞書登録を確認する。** 人名6語。優先度9、長音は `ー`。
3. **末広を開かせない。** 黒留袖の扇子は帯に挿したまま。開いて扇ぐ絵が入ると、
   この層は必ずコメントで指摘します(`lovart_プロンプト集.md` のシートCに書いてあります)。
4. **母の顔を出さない。** カット43の写真立ては背中だけ。台本で一度も顔を出していません。
5. **カット10とカット38は同じ構図**にする。加害①「握られなかった手」の鏡です。
   ここが揃わないと、台本で一番強い因果応報が伝わりません。

## 音声素材のライセンス

`voices/` は MMDAgent Example の HTS音声(mei / takumi)。修正BSDで商用可・クレジット必要。
`voices/*/COPYRIGHT.txt` を読んでください。**本番はVOICEVOXに差し替える前提**なので、
これらは絵コンテ用です。VOICEVOXは概要欄の `音声:VOICEVOX` に加え、
使う話者ごとの規約を確認してください。

Lovartで生成した画像の権利・商用利用可否は、**Lovart側の利用規約を必ず確認**してください。
無料プランは商用利用に条件が付く場合があります。
