# youtube-research — ライフハック雑学チャンネル リサーチツール

@tomorrow_life_hack のネタ探し・競合分析を自動化するツール。APIキー不要(RSS + ページ解析)。

## 別のMacに移す

1. この `youtube-research` フォルダごとコピー(AirDrop・USBメモリ・共有フォルダなど何でもOK)。過去の収集データやお気に入り・台本メモも全部入っているので、コピーするだけで続きが使えます
2. 移した先で `セットアップ.command` をダブルクリック
   - 自動起動の設定(plist)をそのMac・その設置場所に合わせて作り直します
   - ログイン時の自動起動 + 6時間ごとの自動収集を登録します
   - ダッシュボードが自動で開きます
3. 「開発元を確認できないため開けません」と出たら、Finderでファイルを右クリック→「開く」→もう一度「開く」

何度実行しても安全です(前の登録を消して作り直すだけ)。フォルダを置く場所は自由(Desktop・書類フォルダ・どこでもOK)です。

## 見る

- **ダッシュボード**: http://localhost:8770 (常駐。`リサーチを開く.command` をダブルクリックでも開く)
- **テキスト版レポート**: このフォルダの `ネタ候補.md` (収集のたびに上書き)

タブの内容:

| タブ | 内容 |
|---|---|
| 作るべきネタ | 競合が当てていて、自分のタイトルにまだ出ていない言葉を含む動画。上から企画候補 |
| 伸びている動画 | **期間(24時間/3日/7日/30日/90日)を切り替えて**「時速 × チャンネル平均比」順に表示 |
| YouTube検索 | キーワードでYouTubeを直接検索、**最大100件**(期間: 今日〜全期間/再生数順/新着順、ショート除外)。結果にも全ボタン付き |
| SNS・記事 | **X / Yahoo!ニュース / ニュース記事 / はてブ / note / ブログ / TikTok動画 / Instagramリール / Threads を横断検索**。TikTok・InstagramはYahoo!動画検索経由で動画・リール本体(サムネ付き)を取得。ソース選択可、各結果をコピー/メモ保存、全結果からClaude/GPTでネタ出し |
| 新着 | ★お気に入りチャンネルの新着(21日以内)。未読はNEWバッジ + タブに件数。**Mac通知にも出る** |
| 台本メモ | 台本作成用の自由メモ。自動保存。「分析」からリサーチパックを直接保存できる |
| タイトルの型 | 「〜するだけ」「9割が」等の型ごとの再生数中央値。1.0超えの型が狙い目 |
| キーワード | 競合タイトルの頻出語と中央値。★は自分が未使用 |
| チャンネル | 追跡中チャンネルの成績。無関係なものは「除外」ボタンで以後収集しない |
| 自分の成績 | 自分の動画とジャンル中央値の比較 |

## 動画ごとの機能(各行のボタン)

- **分析** — モーダルで詳細分析: 当てはまるタイトルの型 / 再生数の実測推移グラフ / 台本表示 / **コメント欄の反応** / 似たネタの動画
  - コメント要約は「反応が大きいコメント(いいね順)」と「**批判・気になる点(改善のヒント)**」の2部構成+頻出ワード。批判系は嘘・デマ指摘/わかりにくい/長い/既出/タイトル詐欺などの言い回しで自動抽出
- **タイトル** — タイトルをクリップボードへ
- **サムネ** — サムネ画像そのものをクリップボードへ(そのままFigmaや資料に貼れる)。高解像度(maxres)優先
- **台本** — 字幕(手動優先、なければ自動生成)を取得してコピー。一度取得したものはDBにキャッシュ
- **パック** — 「対象動画情報 + 台本 + コメント要約 + 類似動画リスト」のリサーチパックを一括コピー
- **Claude / GPT** — claude.ai / chatgpt.com を開き、**入力欄に分析資料一式を自動で入れる**。内容: 台本作成プロンプト(いいところ/改善点を挙げてから台本化)+タイトル+サムネURL+分析結果(型・時速・平均比)+コメント欄の反応+似たネタの動画+台本。台本が長い場合は抜粋が入り、全文はコピー済みなので送信後に貼り足す。プロンプト文は config.json の `ai_prefill_prompt` で変更可

クリップボードが使えない環境では、選択済みテキストの画面が出るので Cmd+C でコピーする。

## お気に入りと新着通知

- 「チャンネル」タブの★を押すとお気に入り登録。競合以外のチャンネルでもOK(以後RSSを収集する)
- 新着は「新着」タブ(NEWバッジ+件数)と **macOSの通知センター** に出る(6時間ごとの自動収集時)
- 通知を止めるには config.json の `notify_new_favorites` を false に

## 仕組み

- `research.py` が **6時間ごと**に自動実行(launchd)。手動なら:
  - `python3 research.py` … 通常収集(検索 + 全追跡チャンネルのRSS + 上位チャンネルのページ)
  - `python3 research.py --quick` … 検索だけ(2〜3分)
  - `python3 research.py --deep` … 全チャンネルのページも取得(遅い)
  - `python3 research.py --add @handle` … 競合を手動追加
- 検索キーワードに繰り返し登場する同ジャンルのチャンネルは**競合として自動登録**。
  ニュース・海外反応などは `config.json` の `exclude_channel_words` で弾く
- 再生数は毎回スナップショット保存 → 2点間の差分から**実測の時速**を計算
- データは `research.db` (SQLite)。レポートは `ネタ候補.md` と `latest.json`

## 設定 (config.json)

- `keywords`: 検索キーワード。季節が変わったらここを入れ替える(例: 冬なら「結露 対策」「加湿器」等)
- `search_periods`: 検索の期間フィルタ。`today` を含めているので24時間以内の新着も毎回拾う
- `max_rivals`: 自動追跡する競合の上限 (45)
- `discover_min_views`: 競合として登録する平均再生数の下限 (2000)
- `genre_channel_pattern`: この正規表現に合うチャンネル名は同ジャンルとみなし登録されやすくなる

## プロファイル(ジャンルの違うチャンネルを別々に追う)

`--profile <名前>`(または環境変数 `YTR_PROFILE`)を付けると、設定・DB・レポートを
`profiles/<名前>/` に分けて持てる。無指定のときは従来どおりフォルダ直下なので、
ライフハック雑学の既存データはそのまま動く。

同梱のプロファイル:

| 名前 | 対象 | ポート |
|---|---|---|
| (無指定) | @tomorrow_life_hack / ライフハック雑学 | 8770 |
| `okinawa` | 沖縄へ行こう / 沖縄観光。競合に @okipiyo を登録済み | 8771 |

```bash
python3 research.py --profile okinawa   # 沖縄ジャンルの収集
python3 server.py   --profile okinawa   # http://localhost:8771
```

`沖縄リサーチ.command` をダブルクリックすると、ダッシュボードの起動 → ブラウザで開く →
収集、までまとめてやる。ポートが別なので8770のほうと同時に動かして問題ない。

沖縄プロファイルは旅行ジャンル向けに以下を変えてある:

- `keywords` … 「沖縄旅行 気をつけること」「沖縄 観光 モデルコース」など検索需要のある語
- `exclude_shorts: false` … ショートも収集対象(ショート戦略を取るため、伸びているショートを見る)
- `genre_channel_pattern` … 沖縄・離島・観光・旅行・移住
- `ai_prompt_header` / `ai_prefill_prompt` … 「新規撮影はしない前提で、手持ちの実写素材に
  ナレーションとテロップを乗せる構成」で台本を書かせる文言に変更。章ごとに当てる映像素材も出させる

`profiles/<名前>/` の中で git 管理するのは `config.json` だけ(DBやレポートは各Macのローカル扱い)。

新しいプロファイルを足すときは `profiles/<名前>/config.json` を作って `--profile <名前>` で実行する。

## launchd

- `com.user.youtube-research` … 収集を6時間ごと
- `com.user.youtube-research-server` … ダッシュボード常駐 (port 8770)

止める:
```bash
launchctl unload ~/Library/LaunchAgents/com.user.youtube-research.plist ~/Library/LaunchAgents/com.user.youtube-research-server.plist
```
