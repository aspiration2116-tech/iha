> 雑学フォーマットの視聴者は「家庭菜園をやっている人」ではない。

> **10万回台の型で撃てる。**

## 3. なぜ「秋のカメムシ」なのか

| 根拠 | 数字・出典 |
|---|---|
| **季節が今しかない** | **侵入は9月下旬〜10月中旬**（石川県 病害虫防除室だより 第27号）。**9月中旬公開はピークの直前** |
| **2026年は当たり年** | **越冬数が平年の約3倍**（山口県病害虫防除所）。果樹カメムシ類の**注意報が複数県**。農水省も注意喚起 |
| **同ジャンルの天井** | 自チャンネルのダニ **178,453回**（中央値2,563の69.6倍）。害虫ネタは10万〜22万回 |
| **自チャンネルは0本** | カメムシ・越冬害虫は**完全な空白** |
| **買わずにできる** | 「重なっているものをほどく」だけ。チャンネルの型（追加で買うものはいらない）と一致 |
| **根拠が公的** | 石川県・農研機構・堺市・農水省。窓の台本で問題になった「業界団体頼み」が起きない |
| **家庭菜園に繋がる** | カメムシは枝豆・大豆のさやを吸う（農研機構『ダイズカメムシ類対策マニュアル』）。堆肥袋のすきまでも越冬 |

### 「コレ」に機序がある（ここが柱）

**農研機構: クサギカメムシの越冬集団の形成には「暗所選好」と「触角を介した相互刺激」が関与する。**
**石川県: 越冬場所は、樹皮のすきま・落ち葉の中・積み重ねた木材・石の割れ目＝物と物のあいだの狭く暗い場所。**

→ だから対策は薬ではなく、**家の周りの「狭くて暗い重なり」を9月のうちに無くすこと**。
→ 重ねた植木鉢・立てかけた板・落ち葉・巻いたままのすだれ・重ねた堆肥袋。**全部無料。**

### 台本の設計上の防御

**窓の寒さ台本は「中心の事実そのもの」が誤りで柱が崩れた。同じ構造を避けた。**
中心は「カメムシは狭くて暗い場所を選ぶ」という**性質**の事実で、
2026年の発生数（3倍）や侵入時期は**補強にすぎない**。数字が1つ狂っても中心は残る。

## 4. タイトル案（実測の型に従う）

**採用:**

> 【害虫対策】9月にコレをするだけで秋のカメムシが家に入って来なくなるライフハック雑学

- 「コレをするだけ」= **8.01倍**（使った9本の平均98,390回）
- 「9月に」= 数値・時期の明示（1.76倍）。ダニの当たり（178,453回）と同じ「7月にコレをするだけで」の型
- 【害虫対策】= 自チャンネルのダニ回と同じタグ
- **「〇〇」「〜選」「9割が」を使っていない**（0.55／0.38／0.22倍）

**A/B候補（サムネと合わせて3案回すこと）:**

| 案 | タイトル | 狙い |
|---|---|---|
| B | 【害虫対策】秋のカメムシは9月にコレをするだけで家に入って来なくなります | 述語を「なります」にして具体化（競合の222倍事例＝「一掃できます」より「一匹も出なくなります」） |
| C | 【害虫対策】9月にコレをするだけで秋のカメムシが家の中で冬を越せなくなります | 「春まで一緒に暮らす」の恐さを前に出す |

> ⚠️ **競合と同一タイトルにしない。** 害虫ニッチはタイトルのコピーが横行しており、
> 後追いは桁が落ちる（ムカデ 69,528 → 7,665 → 4,520。蚊 221,641 → 19,666 → 14,196 → 4,285 → 1）。
