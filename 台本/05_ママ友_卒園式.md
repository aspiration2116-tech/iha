## この台本について

`10_台本制作マニュアル.md`(台本01を96点「録れ」まで持っていった112件の指摘を規則化したもの)と、
`11_企画10本.md` の「05 年収2千万の旦那くん」の設計にそって書いた一本目です。

**主題は、訪問看護という仕事への敬意です。**
「下の世話でしょ?」は加害者に言わせますが、台本はその仕事を一度も茶化しません。

### 設計どおりに守ったもの

| 規則 | 本文での扱い |
|---|---|
| 主人公は企まない | 彩は証拠を一切持たない。「記録は事業所のもの」と本人が断る |
| 反転は偶然 | 麻衣の再婚相手が、彩が三年通って看取った家の息子。彩は最後まで知らない |
| 泣くのは一回 | 静江さんの字を見る場面のみ |
| 子どもを道具にしない | ひなたは加害の証言をしない。家族の絵と「ここ、まがってるのがいいの」だけ |
| 加害①の鏡 | 麻衣が彩の巾着を受け取らない構図を、藤村が麻衣の腕を取らない構図で返す |
| 金は第三者が回収 | ケアマネジャーの通帳確認 → 拓の叔母が取り立てる。彩は一円も追わない |
