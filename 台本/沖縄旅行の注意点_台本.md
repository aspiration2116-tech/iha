## ① ホテルの場所で旅の半分が決まります (02:30〜05:30 / 3分)

> **競合が2分50秒しか使っていない一方、需要は最大。ここが今回の肝。**

▶素材: 那覇の街並み → 高速道路 → 北部・中部のリゾート → 夕方の渋滞
▷テロップ: 「①ホテルは"どこに泊まるか"が全部」

**【夫】** 1個目。今日いちばん大事です。**ホテルを全部那覇で取らないでください。**

**【妻】** 那覇って便利じゃないの?
**【夫】** 便利です。でも、**観光地のほとんどは那覇にない。**

▷テロップ: 「観光地は"北"と"中部"にあります」

**【夫】** 美ら海水族館、古宇利島、やんばる。全部、北。
アメリカンビレッジや残波岬は中部。那覇にホテルを取ると、
**毎朝、北へ出て、毎晩、南へ帰ってくる**ことになります。

**【妻】** それって……
**【夫】** **毎日、朝と夕方の渋滞に、往復で突っ込む**ということです。
3泊4日で、渋滞に使う時間が合計5〜6時間になる方、本当にいます。

**【妻】** 旅行の半日分だ。

▷テロップ: **「だから、こうしてください」**

**【夫】** **じゃあ、どうするか。** これだけ覚えてください。

- **初日** … 那覇。空港から近くて、夜に国際通りへ行けます
- **中日** … **北部か中部。** ここが旅の本体です
- **最終日** … 那覇か、空港のすぐ近く

**【妻】** 荷物を移すの、面倒じゃない?
**【夫】** 面倒です。でも**ホテルを移すのは1回30分。渋滞は毎日2時間。**
どっちが得かという話です。

▷テロップ: 「高速をケチると、1時間損します」

**【夫】** もうひとつ。**高速道路をケチらないでください。**
那覇から許田(きょだ)まで乗っても千円ちょっと。
一般道の58号線で2時間かけるより、高速なら1時間ちょっとです。
**千円で1時間買えるなら、買ったほうがいい。**

**【妻】** ちなみに、渋滞するのは**南部から中部まで**ね。
**【夫】** そう、そこは正直に言っておきます。**嘉手納から名護、本部より北は、そこまで混みません。**
北に着いてしまえば、道はけっこう空いています。

## ② 運転しない人のための沖縄 (05:30〜08:00 / 2分30秒)

▷テロップ: 「②運転しない、という選択肢」

**【妻】** ここまでレンタカーの話をしたけど、**運転しない方**もいますよね。
**【夫】** います。ペーパードライバーの方、免許のない方、一人旅の方。
**「沖縄はレンタカーがないと無理」と言われがちですが、そんなことないです。**

▷テロップ: 「那覇周辺なら、ゆいレールと路線バスで足ります」

**【夫】** 那覇の中だけなら、**ゆいレール(モノレール)と路線バス**で十分回れます。
首里城も、国際通りも、牧志の市場も、全部行けます。

**【妻】** 北部はどうするの?
**【夫】** 3つ方法があります。

▷テロップ: 「①やんばる急行バス ②高速バス ③現地のバスツアー」

**【夫】** ひとつ、**やんばる急行バスなどの長距離バス。**
那覇空港から美ら海水族館の方面まで、乗り換えなしで行けます。

ふたつ、**高速バス。**

みっつ、これが個人的にいちばんおすすめなんですが、**現地のバスツアー。**

**【妻】** バスツアー?
**【夫】** 沖縄バスさんとか、現地の会社が出しているツアーです。
美ら海、万座毛、今帰仁城跡、みたいに**主要なところを1日で回ってくれる。**
昼食が付いているものもあるので、お店を探す手間もいりません。

**【妻】** 運転の疲れがゼロだもんね。
**【夫】** ゼロです。**帰りのバスで寝ていられる。** これ、けっこう大きいです。

**【夫】** ただ、正直に言っておきます。**沖縄のバスは、遅れます。**
**【妻】** 10分20分は、わりと普通だよね。
**【夫】** 普通です。県民も、それ前提で動いています。
だから**バスで動く日は、予定を詰め込まない。** 1日2〜3か所にする。

**【妻】** それでも十分楽しめるもんね。
**【夫】** 十分です。むしろ、そのくらいのほうが沖縄らしい旅になります。

## ③ レンタカー 予約・受け取り・返却 (08:00〜11:00 / 3分)

▶素材: レンタカー店舗、空港周辺、給油、車の受け渡し
▷テロップ: 「③レンタカーの落とし穴」

**【夫】** 3個目。運転する方向けに、4つだけ。

**▷1. 予約は早く。でも直前も諦めないで**

**【夫】** 夏休み、ゴールデンウィーク、そして**3月**。
**【妻】** 3月?
**【夫】** 卒業旅行です。盲点なんですよ。
ただ、**直前のキャンセルはけっこう出ます。** 諦めずに何社か当たってください。

**▷2. 補償は必ず付けてください**

▷テロップ: 「免責補償 + NOC + レッカー」

**【夫】** 格安レンタカーで、**NOC(ノック)**が付いていないところがあります。
**【妻】** NOCって?
**【夫】** ノンオペレーションチャージ。**車が修理に入っている間の、お店の休業補償**です。
これに入っていないと、こすっただけで数万円を別に請求されます。

**【妻】** 実際に払わされた方の話も聞くもんね。
**【夫】** 聞きます。**免責補償・NOC・レッカー。この3つは必ず確認。** 数千円で保険が買えます。

**▷3. 営業所は「名前」ではなく「場所」で選んでください**

> **ここが競合動画の最大の混乱ポイント。店舗名を推さず、基準だけを渡す。**

▷テロップ: 「どこに泊まるか、で決まります」

**【妻】** よく「どこの営業所がいいですか」って聞かれるよね。
**【夫】** 聞かれます。**でも、店の名前で決めないでください。決まるのは"泊まる場所"です。**

▷テロップ:
```
空港より南(豊見城・糸満)に泊まる → 空港の近くの営業所
空港より北(那覇市内・おもろまち・北部)に泊まる → 北側の営業所
```

**【夫】** 理由は単純で、**受け取ってすぐ、逆方向に走りたくないから**です。
空港の南で借りて、そのまま北のホテルに向かうと、那覇の街を突っ切ることになります。

**【妻】** 名前で「ここがいい」って言われても、自分の泊まる場所と合ってないと意味ないもんね。
**【夫】** そうなんです。**地図で、空港・営業所・ホテルの3点を見てください。** それで決まります。

**【妻】** あと、施設の中にある営業所は、**受付から車まで歩く**ことがあるよね。
**【夫】** あります。荷物が多い方、小さいお子さん連れの方は、そこも見ておいてください。

**▷4. 受け取りと返却の時間**

▷テロップ: 「午後イチの空港は行列 / 返却は満タンで」

**【夫】** 本土からの便がまとまって着くのが昼から午後。その時間の営業所は行列です。
**朝イチで借りる**か、**初日は借りずに2日目の朝から**にする。初日は那覇で十分楽しめます。

**【妻】** 返す時は?
**【夫】** **ガソリン満タン返しが基本**です。会社によって違うので予約時に確認を。
**【妻】** スタンド、ちゃんとあるの?
**【夫】** **那覇や中部は困りません。** ただ、**北部のやんばるは数が減ります。**
北から帰ってくるなら、**名護のあたりで入れておく**と安心です。
**【妻】** 山の中で「残り少ない」は焦るもんね。
**【夫】** 焦ります。ここだけ気をつけてください。

## ④ 走り出す前に知ってほしい沖縄の道 (11:00〜14:30 / 3分30秒)

▶素材: 走行中の車内映像、58号線、高速、雨の路面、信号待ち
▷テロップ: 「④沖縄の道は、少し違います」

**【夫】** 4個目。ここからが本番です。

**▷高速道路は80km/hです**

▷テロップ: 「沖縄自動車道 = 最高速度 80km/h」

**【夫】** 沖縄自動車道の最高速度は**80キロ**。本土の感覚で100キロ出すと、超過です。
**【妻】** 他にも80キロの高速はあるんだけどね。
**【夫】** ありますね。ただ**「高速=100キロ」の感覚で来ると、ここで引っかかります。**

**▷バイクが横から来ます**

▷テロップ: 「発進前と左折前に、必ず左ミラー」

**【夫】** これは県民として正直に言います。**沖縄はバイクのすり抜けが多い。**
**【妻】** 信号で止まると、左からどんどん前に出てくるよね。
**【夫】** だから、**発進する前と、左折する前に、必ず左のミラーを見てください。**
「後ろに誰もいないはず」で寄せると、本当に危ないです。

**▷小さい道から出てきます**

▷テロップ: 「脇道に車が見えたら、少し減速」

**【夫】** 沖縄は、優先道路の意識が薄いところがあります。
細い道から一時停止せずに出てくる車があります。
**【妻】** 「自分が優先だから」でブレーキを踏まないと、ぶつかる。
**【夫】** **脇道に車が見えたら、少し速度を落とす。** それだけで全然違います。

**▷雨とスコール**

▷テロップ: 「雨 + 朝夕 = 車線が消えます」

**【夫】** 沖縄の道路は、**白線が薄い区間**がけっこうあります。
そこに雨と、朝夕の斜めの光が重なると、**車線が本当に見えなくなります。**
**【妻】** 慣れてる私たちでも「どこ走ってるんだろう」ってなるもんね。

**【夫】** それと**スコール**。バケツをひっくり返したような雨で、**一瞬、視界がゼロになります。**
**【妻】** あれは怖いよね。
**【夫】** 無理に走らないでください。**ハザードを出して、安全な場所で止まる。**
15分から30分で、たいてい止みます。

**▷靴の話**

▷テロップ: 「琉球石灰岩は、濡れると滑ります」

**【妻】** これは道じゃないんだけど、**クロックスみたいなサンダル。**
沖縄は琉球石灰岩っていう岩が多くて、**濡れるとツルツルに滑る**んです。
**【夫】** 海岸の岩場、雨の日の階段。県民で、クロックスで岩場に行く人はまずいないです。
**【妻】** かかとが留まるサンダルか、マリンシューズにしてください。

**【夫】** **米軍関係の方の私有車**です。ナンバーに「Y」が入っています。ほかにAやEもあります。

▷テロップ: 「Y / A / E = 米軍関係者の車」

**【夫】** 危ない車という意味ではないです。普通に生活している方の車です。

▷テロップ: 「事故の流れ」

**【夫】** こうなります。

1. まず**日本の警察**を呼ぶ。これは普通と同じ
2. そこに**米軍の憲兵と通訳**が来る

# 制作メモ

## 制作面 — 競合のコメントで苦情が出ていた点

> 競合動画には、内容とは別に3つの苦情が付いていた。**同じ失敗をしない。**

| 苦情 | v2での対処 |
|---|---|
| 「意味のないマスクをはずしてくれたら**もっと聞き取りやすかった**」 | **自宅録音なのでマスクなし。** マイクを口元に近づけ、ノイズを抑える。ここは今回の構成上、自動的に優位に立てる |
| 「17:45〜のBGM、**正直あんまり好きじゃない曲**」 | **BGMは1曲で通さない。** 章ごとに変える。音量は声の1/5以下。注意喚起の章は**BGMを止める**と言葉が立つ |
| 「**めちゃくちゃ広告多いですね**・・・・はぁ。」 | ミッドロールは**章の切れ目だけ**に手動配置。**話の途中に入れない。** 35分なら3〜4か所で十分 |

## 撮影ゼロで作るための素材の当て方

| 章 | 素材の当て方 |
|---|---|
| 先出しまとめ | 各章のハイライトを2〜3秒ずつ。**テロップが主役**なので繋ぎで足りる |
| ①ホテル | 那覇の街・北部リゾート・渋滞。既存カットを繋ぐだけ |
| ②運転しない | ゆいレール・バス・那覇の街。**無ければ地図と図解** |
| ③レンタカー | 店舗外観・給油。**選び方は図解が主役** |
| ④道 | **走行中の車内映像。** 移動時の素材が必ずあるはず |
| ⑤Yナンバー | 58号線。**ナンバープレートは映さない。** 図解で説明 |
| ⑥渋滞 | 夕方の車列。**時間割の表テロップが主役** |
| ⑦バスレーン | 那覇市内の道路・標識。**図解メイン** |
| ⑧距離感 | **地図アニメーションが主役** |
| ⑨海 | ビーチ・波打ち際。既存素材が最も豊富なはず |
| ⑩持ち帰り | 砂・貝殻・サンゴの寄り。**お土産屋の星の砂**があると説得力が出る |
| ⑪陸・御嶽 | やんばるの森・草むら。**御嶽そのものは映さない**配慮を |
| ⑫紫外線 | 強い日差し、日陰、帽子。図解でも可 |

| ⑭買い物 | 国際通り・スーパーの棚。アメリカンビレッジ動画に画があるはず |

**映像が無い章は、テロップと図解で十分もちます。** この動画の価値は絵ではなく情報です。

## 長い場合の分割案

35分が長すぎると感じたら、ここで2本に割れる。

- **前編「移動編」** … ①〜⑧(ホテル・運転・レンタカー・道・渋滞・距離感) 約22分
- **後編「現地編」** … ⑨〜⑮(海・持ち帰り・御嶽・紫外線・天気・買い物・安心) 約16分

どちらも冒頭に先出しまとめを置けば単体で成立する。**2本出せば公開頻度も稼げる。**
