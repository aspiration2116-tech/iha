# 0. v2の何が甘かったか — 放送作家の目で

v2は「正しい情報のリスト」だった。**リストは、読まれるが、見られない。** 具体的には:

| v2の問題 | 何が起きるか | v3での設計 |
|---|---|---|
| **物語がない。15個の箇条書き** | 「次の項目」以外に見続ける理由がない | 旅行の**時間軸**に沿った5幕構成。「今どこにいるか」が常に分かる |
| **感情が平ら**。注意→対策を15回繰り返す | 単調。途中で飽きる | **感情曲線を設計**。緊張と解放を交互に置き、御嶽をクライマックスに |
| **冒頭が弱い**。「はいさい、今日は15個話します」 | 最初の15秒で離脱 | **コールドオープン**。具体的な失敗の"場面"から入る |
| **「2分で全部」が答えを全部先に言う** | 残り33分を見る理由が消える | **地図は渡す、答えは渡さない**。飛びたい人は概要欄の目次で飛べる |
| **妻が「えっ、そうなの?」係** | 掛け合いが嘘くさい。声が2つある意味がない | **キャラクター設計**。夫=心配性で数字の人、妻=楽観的な生活者。海と御嶽で妻が真剣になる"転調"を仕込む |
| **具体的なエピソードがゼロ** | 抽象的な助言は記憶に残らない | 各章に**場面**を置く。冒頭のお父さんは⑤で回収する |

| **全章が同じ長さ・同じ形** | リズムがない | **章ごとに形を変える**。テンポで畳む章、BGMを止めて語る章、笑いで抜く章 |
| **書き言葉**。長文、「〜です。〜ます。」の連続 | 耳で追えない | **耳のための文章**。短文。間を指定。反復。数字 |

# 1. 感情曲線

```
緊張
 ▲
 │ ●冒頭                          ●御嶽(頂点・静かな深さ)
 │ │╲    ●道    ●Y         ●海   ╱│╲
 │ │ ╲  ╱ │╲   ╱│╲  ●距離 ╱ │╲ ╱ │ ╲   ●台風
 │ │  ╲╱  │ ╲╱ │ ╲╱ │╲  ╱  │ ●  │  ╲ ╱│╲        ●旧盆
 │ │ ホテル│ 渋滞│  │ ╲╱   │ハブ  │   ●  │ ╲   ●お土産 ╱│╲
 │ │      │    │  │       │      │ 紫外線│  ╲╱ │╲  ╱ │ ╲
 │ │      │    │  │       │      │      │ 虹  │ ╲╱  │  ╲___●怖がらなくていい
 │ │      │    │  │       │  泳がなくていい  │     │笑い │        ╲
 └─┴──────┴────┴──┴───────┴──────┴──────┴─────┴─────┴─────────╲────▶ 時間
   0    第1幕      第2幕       第3幕       第4幕        第5幕     着地(安心)
```

設計の要点:

- **冒頭**で一度高く上げる(失敗の場面)。すぐ「約束」で少し下げる
- **第1〜2幕**は緊張を階段状に上げる。損する→捕まる→事故→半日消える
- **第3幕・海**で命の緊張。直後に「泳がなくていい」で肩を落とさせる
- **第4幕・御嶽**が頂点。ただし"怖さ"ではなく"深さ"のピーク。ここで動画の格が変わる
- 頂点のあとは**虹**で解放、**台風**で最後の実務的緊張、**笑い**(コーレーグース)で抜く
- **旧盆**でおばあの伏線を回収し、**⑮**で全部を解放して着地

# 3. キャラクター設計

二人の声が違わないと、掛け合いにする意味がない。

| | 夫 | 妻 |
|---|---|---|
| 立場 | 運転担当。数字と理屈で話す | 生活者。感覚と体温で話す |
| 性格 | 少し心配性。「〜なんですよ」 | 楽観的。ツッコミ役。「でもさ」「大丈夫よ」 |
| 役割 | 警告を出す人 | 警告を"人間の温度"に戻す人 |
| **転調** | — | **海(⑧)と御嶽(⑩)で、妻が真剣になる**。普段ゆるい人が真面目になる=視聴者に「ここは本気だ」と伝わる |
| 弱み | — | 「私、中央線で一回入りかけた」など、**自分の失敗を先に言う**。県民でも間違えるという安心 |

# 4. 耳のための書き方(収録時のルール)

- **1文を短く**。「。」で必ず息を吸う
- **(間)** と書いてあるところは、本当に1〜2秒黙る。編集で切らない
- **反復**は意図的。「毎日。毎日です。」は2回言う
- **数字**は必ず声に出す。テロップ任せにしない
- **BGMなし**指定の章は、環境音(波・車)だけ。言葉が立つ
- 台詞は**自分の言葉に直していい**。ただし、章の順番・橋渡し・間の位置は変えない
- 「毎年見ます」「聞いたことある」などの体験談は、**本当に見聞きしたことに差し替える**(末尾の制作メモ参照)

# 制作メモ

## 体験談について(重要)

台本に出てくる「毎年見ます」「7万円払った人の話を聞いた」「北海道から来た方が3.5倍と」などは、
**競合動画のコメント欄で視聴者が実際に書いていた体験を、場面として書き起こしたもの**です。
お二人が本当に見聞きしたことではありません。

**お二人が実際に見たこと・聞いたことに差し替えてください。** 県民として暮らしていれば、
同じ種類の場面(最終日に焦る家族、バスレーンで止められているレンタカー、日焼けで真っ赤な人)は
必ず見ているはずです。**本物の記憶で語ると、声が変わります。** そこが視聴者に伝わります。

差し替えが難しいものは「〜という話を聞いたことがある」「〜という方がいる」の形にしてください。
自分が見ていないことを「見た」とは言わないこと。

## 音・BGM・広告(競合のコメントで苦情が出ていた3点)

| 苦情 | 対処 |
|---|---|
| マスクで聞き取りにくい | 自宅録音なので構造的に起きない。マイクは口元15cm。二人の音量を揃える |
| BGMが不快 | **1曲で通さない。** 幕ごとに変える。音量は声の1/5以下。**⑧海と⑩御嶽はBGMを止める**(台本に指定済み) |
| 広告が多い | ミッドロールは**幕の切れ目だけ**に手動配置(4か所)。**話の途中に入れない** |

## 素材の当て方(撮影ゼロ)

| 章 | 当て方 |
|---|---|
| コールドオープン | 夕方の渋滞・テールランプ。**空港方向の空**があると効く。無ければ渋滞だけで成立 |
| ①ホテル | **地図アニメが主役。** ピンが北と中部に落ちる動きを作る。街と渋滞は繋ぎ |
| ②運転しない | ゆいレール・バス・那覇の街。無ければ地図と図解 |
| ③レンタカー | 店舗・給油。**空港・営業所・ホテルの3点地図**が主役 |
| ④道 | **走行中の車内映像。** 6項目それぞれに1カット。無い項目はテロップで |
| ⑤渋滞 | 車列・時計。**表テロップが主役**。最終日は瀬長島の画で締める |
| ⑥Yナンバー | 58号線・基地のフェンス。**ナンバーは映さない。** 事故の流れは図解 |
| ⑦距離感 | **地図アニメ**(那覇→美ら海に線が伸びる) |
| ⑧海 | **白波と静かな水面の対比カット**が命。ネット、岩場。素材が一番豊富なはず |
| ⑨持ち帰り | 砂・貝殻・白いサンゴの寄り。**星の砂の瓶**があると説得力が出る |
| ⑩ハブ・御嶽 | 森・草むら → 集落・石垣・木漏れ日。**御嶽そのものは映さない** |
| ⑪紫外線 | 強い日差し、日陰、羽織りもの |
| ⑫天気 | 晴れ→雨→**虹**。虹の素材があるなら、ここに全部使う |
| ⑬買い物 | 国際通り・スーパーの棚・そば屋。アメリカンビレッジ動画に画があるはず |
| ⑭旧盆 | 集落・夕暮れ・シャッター。エイサーがあれば強い |
| ⑮怖がらなくていい | **一番きれいな画を全部ここに。** 夕日・海・笑顔。トーンを明るく転換 |

映像が無い章は、テロップと図解で持ちます。この動画の価値は絵ではなく、情報と、声です。

## 長い場合の分割案

37分が長いと感じたら、幕の切れ目で2本に割れる。

- **前編「移動編」** 第1幕+第2幕(①〜⑥)約18分 — コールドオープンをそのまま使う
- **後編「現地編」** 第3幕〜第5幕(⑦〜⑮)約19分 — 冒頭に「前編で道の話をしました。今日は着いてからの話」を30秒足す

**後編に⑮があるので、感情の着地は後編に残る。** 前編は⑥の「知っていれば慌てないで済む」で軽く着地させる。

## 公開前に必ず確認(県民のお二人で答え合わせを)

1. **高速道路の80km/h** — 区間による違いがないか
2. **Yナンバー事故の流れ** — 憲兵と通訳が来るまでの時間の実際
3. **バスレーンの区間と時間** — 区間名を出すなら最新情報に
4. **那覇→美ら海の所要時間** — 高速利用時の現実的な数字
5. **ハブクラゲに酢** — 応急処置として現在も推奨されているか
6. **砂・サンゴ・星の砂の持ち帰り** — **どの法令・条例が根拠か。断定するので必ず確認**
7. **やんばるのガソリンスタンド事情** — 「名護で入れておく」で合っているか
8. **旧盆の日付** — 公開年に合わせる。**固定コメントで毎年更新**
9. **ATMの限度額** — 銀行で違うので、断定を避けるか具体名を出すか
10. **長距離バスの路線名** — やんばる急行バス等、現在の運行状況
11. **御嶽の見分け方の表現** — 地域によって形が違うので、お二人の地元の実感に寄せて言い換えてよい
