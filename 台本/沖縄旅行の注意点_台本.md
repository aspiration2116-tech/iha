▷テロップ: 「沖縄県民が本音で言います」

**【夫】** はいさい。沖縄生まれ、沖縄育ちの(名前)です。
**【妻】** (名前)です。
**【夫】** 今日は、沖縄に遊びに来てくださる方に「これだけは知っておいてほしい」ことを、県民の本音で話します。

**【妻】** 観光地の紹介じゃないの?
**【夫】** 今日は違う。楽しむ話の前に、これを知らないと一日まるごと損する、っていうことが沖縄はけっこうあるんですよ。

**【妻】** 私たち、レンタカーの後ろを走っててヒヤッとすることが本当に多くて。

## ① ホテルの場所で旅の半分が決まります (01:00〜04:00 / 約3分)

> **この章が今回の一番の肝。競合が2分50秒しか使っていない一方、需要は最大。厚く作る。**

▶素材: 那覇の街並み → 高速道路 → 北部・中部のリゾートの画 → 渋滞の車列
▷テロップ: 「①ホテルは"どこに泊まるか"が全部」

**【夫】** 1個目。これが今日いちばん大事です。**ホテルを全部那覇で取らないでください。**

**【妻】** えっ、那覇って便利じゃないの?
**【夫】** 那覇は便利。でも、観光地のほとんどは那覇にないんですよ。

▷テロップ: 「観光地は"北"と"中部"にある」

**【夫】** 美ら海水族館、古宇利島、やんばる。全部北です。アメリカンビレッジや残波岬は中部。
那覇にホテルを取ると、**毎朝、北に向かって出て、毎晩、南に向かって帰ってくる**ことになります。

**【妻】** それって……
**【夫】** そう。**毎日、朝と夕方の渋滞に、往復で突っ込むことになります。**

▶素材: 夕方の渋滞、車のテールランプ
▷テロップ: 「毎日 往復で渋滞にハマる」

**【夫】** 3泊4日で、渋滞に使う時間が合計で5時間とか6時間になる方、本当にいます。
**【妻】** 半日分なくなっちゃうってこと。
**【夫】** 旅行の半日ですよ。もったいないです。

▷テロップ: 「おすすめの組み方」

**【夫】** じゃあどうするか。おすすめはこうです。

- **初日** … 那覇(空港から近い。夜に国際通りへ行ける)
- **中日** … **北部か中部**に泊まる。ここが本体
- **最終日** … 那覇か、空港の近く

▷テロップ: 「初日=那覇 / 中日=北部・中部 / 最終日=空港の近く」

**【妻】** 荷物を移すのが面倒じゃない?
**【夫】** 面倒です。でも、**その面倒くささより、渋滞で消える時間のほうがずっと大きい**です。
ホテルを移すのは1回30分。渋滞は毎日2時間ですから。

**【夫】** それともうひとつ。**高速道路をケチらないでください。**
**【妻】** 沖縄の高速、そんなに高くないもんね。
**【夫】** 那覇から許田(きょだ)まで乗っても千円ちょっとです。一般道の58号線をずっと走って
2時間かけるより、高速で1時間ちょっと。**千円で1時間買えるなら、買ったほうがいい。**

▷テロップ: 「高速をケチると1時間損します」

**▷2. 補償は必ず付けてください**

▷テロップ: 「免責補償 + NOC + レッカー」

**【夫】** 格安レンタカーで、**NOC(ノック)が付いていない**ところがあります。
**【妻】** NOCって?

**【妻】** それは知らなかったら怖い。
**【夫】** 免責補償とNOCとレッカー。この3つは必ず確認してください。数千円で保険が買えます。

**▷3. 受け取りは、到着日の午後を避ける**

▷テロップ: 「午後イチの空港は大行列」

## ③ 走り出す前に知ってほしい沖縄の道 (06:30〜10:00 / 約3分30秒)

▶素材: 走行中の車内映像(フロントガラス越し)、58号線、高速、雨の路面
▷テロップ: 「③沖縄の道は本土と違います」

**【夫】** 3個目。ここからが本題です。

**▷高速道路は80km/hです**

▷テロップ: 「沖縄の高速 = 最高速度 80km/h」

**【夫】** 沖縄自動車道の最高速度は**80キロ**。本土の感覚で100キロ出すと、それは超過です。
**【妻】** これ、知らない人多いよね。
**【夫】** 「知らずに100で走ってました」というお声、本当によく聞きます。

**▷バイクが横から来ます**

▶素材: 信号待ちの車列、街中の走行カット
▷テロップ: 「信号待ち→前にバイクが並びます」

**【夫】** これは県民として正直に言います。**沖縄はバイクのすり抜けが多い**です。
**【妻】** 信号で止まると、左からどんどん前に出てくるもんね。
**【夫】** だから、**発進する前と、左折する前に、必ず左のミラーを見てください。**
本土の感覚で「後ろに誰もいないはず」と思って寄せると、本当に危ないです。

**▷小さい道から、平気で出てきます**

▷テロップ: 「幹線道路を走っていても減速を」

**【夫】** 沖縄は、優先道路の意識がわりと薄いところがあります。
細い道から、一時停止せずに出てくる車があります。
**【妻】** 「自分が優先だから」でブレーキを踏まないでいると、ぶつかる。
**【夫】** 幹線道路を走っていても、脇道に車が見えたら、少し速度を落とす。それだけで全然違います。

**▷雨の日は線が見えません**

▶素材: 雨の日の走行カット(あれば)、濡れた路面
▷テロップ: 「雨 + 朝夕 = 車線が消えます」

**【夫】** 沖縄の道路は、そもそも**白線が薄くなっている区間**がけっこうあります。
そこに雨と、朝夕の斜めの光が重なると、**車線が本当に見えなくなります。**
**【妻】** 慣れてる私たちでも「どこ走ってるんだろう」ってなるもんね。
**【夫】** 前の車との距離を取って、無理に車線変更しない。これだけ気をつけてください。

**▷それと、路面が滑ります**

▷テロップ: 「琉球石灰岩は濡れると滑ります」

**【妻】** あと、これは道じゃないんだけど、**クロックスみたいなサンダル**。
**【夫】** ああ、滑るね。
**【妻】** 沖縄って琉球石灰岩(りゅうきゅうせっかいがん)っていう岩が多くて、
**濡れるとツルツルに滑る**んです。海岸の岩場とか、雨の日の階段とか。
**【夫】** 県民でクロックスで岩場に行く人、たぶんいないです。
**【妻】** かかとが留まるサンダルか、マリンシューズにしてください。

## ④ Yナンバーの車とぶつかったら (10:00〜12:30 / 約2分30秒)

> **コメントで最も反応が集中した論点。独立章にする。**

▶素材: 基地周辺の道路、58号線、ナンバープレートは映さずテロップで説明
▷テロップ: 「④Yナンバーってなに?」

**【夫】** 4個目。これは沖縄ならではの話です。**Yナンバー**。

**【妻】** 見たことあるけど、何なの?
**【夫】** **米軍関係の方の私有車**です。ナンバープレートに「Y」が入っています。
ほかにAやEのナンバーもあります。

▷テロップ: 「Y / A / E = 米軍関係者の車」

**【夫】** 別に危ない車という意味ではないです。普通に生活している方の車です。
ただ、**万が一ぶつかってしまったときの手続きが、日本の車同士とは違います。**

▷テロップ: 「事故の流れ」

**【夫】** 流れとしてはこうです。

1. まず**日本の警察**を呼ぶ。これは普通と同じ
2. そこに**米軍の憲兵(MP)と通訳**が来る
3. 日本の警察と、米軍側と、**同じことを2回聞かれる**

**【妻】** 2回?
**【夫】** はい。そして、**憲兵が現場に着くまでに数時間かかることがあります。**
その間、現場で待つことになります。

▷テロップ: 「その日の予定は、まず飛びます」

**【妻】** 半日つぶれちゃうね……。
**【夫】** だから何より、**ぶつからないこと**です。車間を取る。無理な割り込みをしない。

▷テロップ: 「①ナンバーを控える ②写真を撮る ③レンタカー会社に連絡」

**【夫】** もし当てられてしまったら、**相手のナンバーを控える。写真を撮る。
すぐレンタカー会社と警察に連絡する。** これだけは覚えておいてください。
**【妻】** 自分で相手と示談にしようとしないこと。
**【夫】** 絶対にやめてください。必ず警察を呼んでください。

## ⑤ 渋滞の時間割(これだけは覚えて) (12:30〜15:00 / 約2分30秒)

▶素材: 朝の渋滞、夕方の渋滞、58号線、北谷〜那覇の車列
▷テロップ: 「⑤沖縄の渋滞には"時間割"があります」

**【夫】** 5個目。渋滞です。沖縄の渋滞は、**時間がだいたい決まっています。**

▷テロップ(表形式で出す):
```
朝  7:30〜 9:00   那覇に向かう方向がびっしり
夕  17:00〜20:00   那覇から北へ向かう方向がびっしり
```

**【夫】** 通勤と通学の時間です。観光の渋滞じゃなくて、**生活の渋滞**なんですよ。
**【妻】** だから毎日ある。
**【夫】** 毎日あります。土日は少しマシですが、それでも観光の車で混みます。

**▷対策は「ずらす」だけ**

▷テロップ: 「朝は9時過ぎに出る / 夕方は20時まで遊ぶ」

**【夫】** 朝、7時半に出ると渋滞にハマります。**9時過ぎに出たほうが、結果的に早く着きます。**
**【妻】** 早起きして損するって、変な感じだけどね。
**【夫】** 夕方も同じで、17時に切り上げて帰ると、いちばん混んでいる時間に乗ってしまう。
**どこかで夕ごはんを食べて、20時ごろ動く。** そのほうがずっと楽です。

**▷最終日だけは特別です**

▷テロップ: 「最終日は"逆算"してください」

**【夫】** これは本当に気をつけてほしい。**帰りの飛行機が夕方の便の方。**
平日だと、**16時ごろから北谷(ちゃたん)〜豊見城(とみぐすく)のあたりが動かなくなります。**

**【妻】** 空港に着かない、ってこと?
**【夫】** 間に合わなかった方、実際にいます。
最終日は、**空港の近くで過ごす**のがいちばん安全です。

▷テロップ: 「最終日は空港の近く(ウミカジテラス・瀬長島など)」

**【夫】** 瀬長島のウミカジテラスとか、あのあたりなら、渋滞に関係なく空港に入れます。
**【妻】** 最後まで遊べて、しかも安全。
**【夫】** 最終日に北部の予定を入れるのだけは、やめてください。

## ⑥ バスレーンと中央線の罠 (15:00〜16:30 / 約1分30秒)

▷テロップ: 「⑥知らないと捕まります」

**▷バスレーン**

▷テロップ: 「朝夕の一部区間は"バス専用"になります」

**【夫】** 那覇の市内には、**朝と夕方だけバス専用になる車線**があります。

**▷中央線が動く道があります**

▷テロップ: 「時間帯で車線の向きが変わります」

**【妻】** あと、中央線が移動する道もあるよね。

**【妻】** これ県民でも戸惑うよ。
**【夫】** 戸惑います。だから**前の車についていく**のがいちばん安全です。
自分だけ違う車線にいたら、それは間違っています。

## ⑦ 沖縄の距離感は地図より遠い (16:30〜18:00 / 約1分30秒)

▷テロップ: 「⑦地図で見ると近いのに、遠い」

▷テロップ: 「那覇 → 美ら海水族館 = 片道 約2時間」

一般道だと2時間半、渋滞に当たればもっとかかります。

**【妻】** 往復4時間か……。
**【夫】** そうなんです。「往復で、行きの飛行機より長いじゃないか」と驚かれる方がいます。

**【妻】** じゃあ美ら海は行かないほうがいい?
**【夫】** いえ、**行ってほしい**です。ただ、**美ら海に行く日は、美ら海の日にしてください。**

# 制作メモ

## 撮影ゼロで作るための素材の当て方

| 章 | 素材の当て方 |
|---|---|
| ①ホテル | 那覇の街・北部リゾート・渋滞。既存の各地カットを繋ぐだけ |
| ②レンタカー | 店舗外観・空港周辺。無ければ**テロップと図解**で持たせる |
| ③道 | **走行中の車内映像**。各地へ移動するときの素材が必ずあるはず |
| ④Yナンバー | 58号線や基地周辺の道。**ナンバープレートは映さない**。図解で説明 |
| ⑤渋滞 | 夕方の車列。**時間割は表テロップが主役**なので映像は繋ぎでいい |
| ⑥バスレーン | 那覇市内の道路・標識。**図解メイン** |
| ⑦距離感 | **地図アニメーション**が主役。移動カットを添える |
| ⑧海 | ビーチ・波打ち際。既存素材が最も豊富なはず |
| ⑨陸・御嶽 | やんばるの森・草むら。**御嶽そのものは映さない**配慮を |
| ⑩天気 | 晴れ・雨・虹。過去素材から拾う |
| ⑪買い物 | 国際通り・スーパーの棚。アメリカンビレッジ動画に使える画があるはず |
| ⑫旧盆 | 集落の風景・静かな街。エイサーの素材があれば強い |

**映像が無い章は、テロップと図解で十分もちます。**
この動画の価値は絵ではなく情報なので、そこは割り切って構いません。

## 公開前に必ず確認してほしいこと(お二人が県民なので、答え合わせをお願いします)

1. **高速道路の最高速度80km/h** — 区間による違いがないか
2. **Yナンバー事故の実際の流れ** — 憲兵と通訳が来るまでの時間、任意保険の加入状況
3. **バスレーンの具体的な区間と時間** — 動画で区間名を出すなら最新の情報に
4. **中央線が変わる道の場所** — 名前を出すかどうか
5. **那覇→美ら海の所要時間** — 高速利用時の現実的な数字
6. **ハブクラゲに酢** — 応急処置として現在も推奨されているか
7. **旧盆の日付** — 公開する年の日付に更新(毎年変わるので**固定コメントで毎年更新**すると長く効きます)
8. **ATMの限度額** — 銀行によって違うので断定を避けるか、具体名を出すか

## この動画を出したあとにやること

- **ショートを10本切り出す**。1項目=1ショート。「Yナンバー」「渋滞の時間割」「お土産はスーパー」あたりは
  単独で強い。すべてこの動画から作れる
- **固定コメントで情報を更新**し続ける。旧盆の日付と、閉店・新店の情報
- コメントで来た質問を集めて、**続編「県民が質問に全部答えます」**を作る。これも撮影ゼロ
- リクエストとして既に出ている **ダイビング・シュノーケリングのおすすめ** は次の企画候補
