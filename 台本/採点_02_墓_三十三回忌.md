#### 致命1. L577 泰然「ついでに、堤さんの過去帳も」 —— 住職に、寺が一番やらない一手をやらせている

**なぜダメか。**

二つ壊れている。

ひとつめ。**過去帳は公開しない。**1975年の部落地名総鑑事件以降、全日本仏教会と各宗派は過去帳の閲覧・書写・第三者への開示を禁じる通達を出している。今でも寺は檀家本人に対してすら該当箇所しか見せない。**それを22人の前で「ついでに」読み上げる住職は存在しない。**この題材を見に来る層には、法事を出す側・受ける側が大量にいる。この一行だけでコメント欄が「住職がこんなことするわけない」で埋まる。しかもやらせている相手が**恩人**だ。台本の道徳的な支えが、反転の一番高い場所で自分から折れる。

ふたつめ。**読み上げた中身が過去帳の記載事項ではない。**過去帳に載るのは戒名・俗名・没年月日・行年だ。L579「こちらへ移られたのは、平成六年」(入檀の年)もL581「最初にお預かりしたのが、誠さんのお祖父さんです」(最初の埋葬)も、過去帳ではなく**檀家帳・墓地台帳・寺の沿革誌**の情報だ。作法を知っている人ほど、二重に引っかかる。

そして皮肉なことに、この台本は**L551で「寺の記録を、読み上げます」と正しく言えている**。寄進の記録と過去帳を区別できていたのに、26行後に自分で混ぜた。

**どう直すか。** 語を替え、「ついでに」を捨てる。読む物をト書きで指定する。

- L577 → **泰然**「堤さんの檀家帳も、お持ちしました」
- L579 → **泰然**「お入りになったのは、平成六年」
- L581 → そのまま
- L575の次(ト書き)に一行:
  > ト書き:泰然の膝の前に、和綴じの帳面が二冊。一冊は寺の寄進帳、もう一冊は檀家帳。**過去帳は出さない**。中の文字は映さない。

#### 致命2. L754-758 —— 120万円が返る理由が、どこにも無い

**なぜダメか。**

転落で動く金はこれ一本だ。その一本の因果がこうなっている。

```
L754  石材店が、名義の訂正に来ました。
L756  石屋「施主さまと、お支払いのお名前が違いますので」
L758  百二十万円は、堤が返すことになりました。
```

**三年前に完工して完済された取引**(L231/L267)の名義を、石材店がいま訂正しに来る動機が無い。工事は終わり、金は入っている。訂正する対象が存在しない。そして仮に訂正したところで、**石材店には堤家に120万を払わせる力が一切無い。**菜穂と誠のあいだの立替金は私人間の貸借で、石材店は当事者ですらない。

マニュアル§2-4「主人公が金を取り立てない。回収は第三者にやらせる」を守ろうとした判断は正しい。**選んだ第三者が間違っている。**しかも本文には、ちゃんと動機と圧力を持った第三者がすでに二人いる——L629 親族A「じゃあ堤は、六十万しか出しとらんのか」と、区画が欲しいL366 久美だ。使っていない。

**どう直すか。** 石材店が本当に来る理由は一つだけある。**墓誌・竿石の「建之者」の名義**だ。金を出した人の名前を石に彫るのは石屋の仕事で、三年経っていても「彫り直すか」を訊きに来るのは自然だ。そしてこれは、**未回収の伏線を二つ同時に回収する**(L426「親父さんの磨いた石」/ L79「墓石ってのはな、名前を彫るための石だ」)。

- L754 → **菜穂**石材店が、建之者の彫り直しに来ました。
- L756 → **石屋**「建之のお名前を、どういたしましょうか」
- L756の次に一行追加 → **石屋**「三分の二を出された方のお名前を、伏せたままにはできません」
- L758 → そのまま(「百二十万円は、堤が返すことになりました。」)

これで堤家は「墓石に森口菜穂と彫らせる」か「120万返す」かの二択になる。**芳江が最も嫌う選択肢**が突きつけられて、金が動く理由ができる。祖父の「名前を彫るための石だ」が、堤家の墓の上で牙になる。

#### 重大3. L283 菜穂「いつか、父の遺骨を、こちらのお墓に」 —— 加害④(最強の加害)の動機が本文に無い

**なぜダメか。** この六行前(L277-281)で、菜穂は**市営霊園の名義を自分が継いだばかり**だ。父の墓はある。承継者もいる。**なぜ義実家の墓に父の骨を移したがるのか、本文に一行も無い。**しかも祖父はL91で「うちの墓は、あの寺には置かん」と言い切っている。菜穂の言い分は、祖父の遺志にも自分の持ち物にも反している。

#### 重大4. L744「墓はなくても、位牌は、あの寺にあります」 —— 祖父の原則と正面から矛盾する

**なぜダメか。** 祖父の一本の筋はこれだ。

```
L91  祖父「うちの墓は、あの寺には置かん」
L95  祖父「置いたら、見返りになる」
L697 泰然「『置いたら、見返りになる』」
L699 泰然「四十年前、あの人はそう言って帰った」
```

墓を置かなかった理由が「見返りを取ったと思われたくない」なら、**位牌堂に位牌を預けるのはもっと直接的な見返り**だ。位牌預かりには供養料が要り、檀家関係か永代供養の契約が前提になる。寄進者が自家の位牌だけ寺に置くのは、祖父が避けた形そのものだ。

しかもこの矛盾が乗っている場所が悪い。L736-748は**加害①の鏡**(ト書きL731-732で構図まで指定した、台本の設計上いちばん大事な返し)だ。その着地点が、祖父の原則を踏みにじって成立している。

- L744の次に一行追加 → **菜穂**祖父には、言っていないそうです。
