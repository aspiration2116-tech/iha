## 02「夫の実家の墓に入る気か」

**タイトル**
```
【漫画】義母「寺に一円も出せん家の嫁が墓に入る気ｗ」義姉「私の区画も空けといて♡」私「わかりました」→三十三回忌で住職が"寄進者"を読み上げた結果ｗ【スカッと】
```

| 要素 | 内容 |
|---|---|
| 主人公 | 森口菜穂(34)。市役所の戸籍課。祖父母に育てられた |
| 守る対象 | 亡き父・森口和夫。菜穂が12歳のとき事故で他界。墓は市営霊園の小さな一区画 |
| 恩人 | 妙相寺の住職・大西泰然(78)。菜穂の祖父と同世代 |
| 加害者 | 義母・堤芳江(64)/ 夫・堤誠(38)/ 義姉・堤久美(41) |
| 反転の場 | 堤家の先祖の三十三回忌。親族22人 |

**加害の階段**
1. **言葉** 顔合わせで芳江「森口さんのお墓、市営ですって?」「うちは代々、妙相寺ですの」
2. **身につけるもの** 法事に父の形見の数珠を持参 → 芳江「そんな安物、堤の名が泣くわ」と替えさせる
3. **金** 堤家の墓の改修費180万を「嫁の実家が出すのが筋」/ 菜穂が黙って120万を出す
4. **存在の否定** 「あなたのお父様のお骨、うちの墓には入れられません」「無縁仏でいいでしょう」

**一線** 父の十七回忌の日に、菜穂が休みを取ったことを芳江が「堤の法事より実家を取るの?」と責める。
菜穂は父の法要に行けない。

**受諾の条件** 「わかりました。ただ、三十三回忌には、ひとりだけお呼びしたい方がいます」

**反転** 三十三回忌。住職が読経のあと、堤家の過去帳と**霊園の記録**を読み上げる。
妙相寺の山門と墓地の土地は、**四十年前に森口家(菜穂の祖父)が寄進したもの**。
堤家はそこを「代々」と呼んでいた。住職「森口さんには、この寺が助けられました」

**因果応報** 芳江が親族に「代々」を語れなくなる。改修費の120万は、堤誠の兄が立て替えを迫られる。
芳江は次の法事の連絡網から外れる(**同じ手口で返す**)。

**伏線10組** 父の数珠 / 祖父の作業着 / 戸籍課という職業(菜穂は名義を読む職業) / 住職の「泰然」の字を祖父が書いた /
市営霊園の小さな区画 / 「代々」の口ぐせ / 改修費の領収書 / 父の十七回忌に行けなかった日 /
祖父が寺に運んだ石 / 山門の寄進者板(文字は映さない)

**加害①の鏡** 顔合わせで芳江が菜穂の差し出した数珠を受け取らなかった構図を、
法要で住職が芳江の差し出した供物を受け取らず、森口家の位牌に一礼する構図で返す。

**コールドオープン** 住職「ところで、この山門は、どなたが建てられたかご存じですか」

## 03「妊娠は病気じゃない」

**タイトル**
```
【漫画】夫「妊娠は病気じゃねえ、明日も出ろｗ」義母「うちは臨月まで畑に出たわ♡」私「わかりました」→創立記念式で産業医が"診断書の日付"を読んだ結果ｗ【スカッと】
```

| 要素 | 内容 |
|---|---|
| 主人公 | 白石千尋(31)。夫と同じ会社の経理課。妊娠7か月 |
| 守る対象 | お腹の子。切迫早産の診断 |
| 恩人 | 産業医・郡司里子(59)。月一で会社に来る。千尋の母の同級生 |
| 加害者 | 夫・白石亮(34)営業課 / 義母・白石トシ(66) |
| 反転の場 | 創立六十周年記念式典。家族同伴・社員と家族300人 |

**加害の階段**
1. **言葉** 「妊娠は病気じゃねえよ」「つわりは気の持ちよう」
2. **身につけるもの** 母の形見のマタニティ用の帯を「みっともない」と捨てられる
3. **金** 産休の手当を「家計に入れろ」と全額取り上げる。ベビー用品は義母のお下がり
4. **存在の否定** 切迫早産の診断書を亮が握りつぶし、上司に「本人が休みたいだけ」と報告

**一線** 千尋が売り場で倒れる。亮は駆けつけず「大げさにするな、俺の評価に響く」。

**受諾の条件** 「わかりました。式典には出ます。ただ、郡司先生と同じ席にしてください」

**反転** 式典。表彰される亮の「家族への感謝」のスピーチのあと、産業医の郡司が壇上へ。
郡司は**産業医として提出済みの就業制限の意見書の日付**を読む。
「四月九日。切迫早産、就業制限。この日、白石さんは棚卸しに立っていました」
社長「誰が指示した」。亮の直属の上司が立てない。

**因果応報** 亮は労務管理違反で営業から外れる。義母は社宅の付き合いから外れる。
千尋の産休の手当は、口座名義が千尋であることが人事で確認され、全額戻る。

**伏線10組** 母の帯 / 郡司が母の同級生 / 経理課という職業(千尋は数字を読む) / 意見書の控え /
「気の持ちよう」の口ぐせ / 社宅の階段 / お下がりのベビー服のほつれ / 亮が新人のとき千尋に助けられた話 /
棚卸しの日付 / 千尋が一度もつわりを口にしなかったこと

**加害①の鏡** 亮が千尋の差し出した診断書を受け取らなかった構図を、
式典で社長が亮の差し出した表彰盾を受け取らない構図で返す。

**コールドオープン** 郡司「社長。この会社の産業医として、ひとつ申し上げます」

## 05「年収2千万の旦那くん」

**タイトル**
```
【漫画】ママ友「年収2千万の人と再婚するのｗ」夫「お前より気が利く♡」私「わかりました」→卒園式の茶話会で相手が私を見て青ざめた結果ｗ【スカッと】
```

|---|---|
| 主人公 | 三雲彩(36)。訪問看護師。娘・ひなた(6) |

| 恩人 | 夫の祖父・三雲源一(89) |

**加害の階段**
1. **言葉** 麻衣が園のグループLINEで「看護師さんって、下の世話でしょ?」
2. **身につけるもの** ひなたの手作りの通園バッグを「うちの子が可哀想」と言われ、彩が買い替える
3. **金** 拓が家計から30万を抜き、麻衣の子の習い事の月謝を払っていた
4. **存在の否定** 拓「ひなたは麻衣さんに懐いてる。お前より母親らしい」

**反転** 茶話会。麻衣が再婚相手を連れてくる。相手は**彩の訪問先の家族**で、

三年通った家の表札 / グループLINEの既読 / ひなたが描いた家族の絵(4人ではなく3人)/
拓の財布のレシート / 源一が彩に渡した古い体温計 / 月謝袋 / 彩が一度も言い返さなかったこと

**加害①の鏡** 麻衣が彩の差し出した手作りの品を受け取らなかった構図を、

**コールドオープン** 再婚相手「麻衣さん。君が言っていた"下の世話"は、この人のことか」

## 企画段階の誤りと訂正

執筆時に担当が見つけた、この企画書自体の事実誤り。**同じ間違いを繰り返さないため残す。**

| 誤り | 正しくは | どこ |
|---|---|---|
| 「手形を一度も落とさんかった」を褒め言葉として使った | **「手形を落とす」は支払期日に決済すること。**「落とさんかった」は「一度も払わなかった」の意 | 11 |
| 「献花」 | **供花。**献花は無宗教式・キリスト教式のもの。読経と焼香のある仏式は供花 | 11 |
| 年金を義姉の口座に振り込ませる | **公的年金は本人名義の口座にしか振り込めない。**通帳と印鑑を握る形にする | 08 |
| 給与を夫名義の口座に振り込ませる | **給与振込は本人名義口座が原則。**振込後に通帳と印鑑を取り上げる形にする | 09 |
| 退職金の受取人を他人にする | **退職手当は本人名義の口座にしか振り込めない** | 09 |
| 他人名義の通帳を主人公に指定する | 名義は動かせない。**任意後見契約(公正証書)と銀行の代理人届**で同じ結末になる | 04 |

| 栄養教諭が自分の子の在籍校に単独配置 | **共同調理場方式**なら実在の配置として通る | 10 |
