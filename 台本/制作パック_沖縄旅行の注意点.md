# 4. サムネイル指示書

### 3案つくって、テスト機能で回す

| | 大テロップ(上3分の1) | 帯(下) | 背景 |
|---|---|---|---|
| **A** | **沖縄県民が本音** | やりがちな失敗15選 | 海か国際通り |
| **B** | **知らずに来ると損** | 沖縄の落とし穴 | 夕方の渋滞 |
| **C** | **県民はヒヤヒヤしてます** | 沖縄旅行の注意点 | 走行中の道 |

### 作り方のルール

- 文字は**2〜4語**。スマホの一覧で読めるサイズ
- **極太ゴシック + 白フチ(太め) + 黒フチ(さらに外側)**
- 文字色は **白か黄色**。背景が明るいなら濃紺
- **お二人は右下に小さく。** 顔は主役にしない
- 「15」の数字は**特大**にする。数字は目を引きます

### タイトル案(3案)

```
A(推奨)
【沖縄旅行の注意点】沖縄県民の夫婦が本音で言う、観光客がやりがちな失敗15選

B
沖縄旅行で絶対やってはいけないこと15選｜沖縄県民が本音で解説【保存版】

C
【沖縄県民が本音】沖縄旅行で9割が知らない注意点15選｜レンタカー・渋滞・海
```

# 5. テロップ台本(章順)

映像編集のとき、この順に入れてください。**★は大きく、長めに出す**もの。

```
01 オープニング
   沖縄県民の夫婦が、本音で

02 今日の流れ
   ★予約の前に / ハンドルを握ったら / 海へ行く日 / 沖縄を歩くとき / 財布と、心の話

03 ホテル
   観光客の動き = 県民の通勤の動き
   ★初日 → 那覇 ／ 中日 → 北部か中部 ／ 最終日 → 空港の近く
   高速をケチると、1時間損します

04 運転しない
   那覇の中は、ゆいレールとバスで足ります
   ①長距離バス ②高速バス ③現地のバスツアー
   バスは、遅れます(10〜20分は普通)

05 レンタカー
   こすっただけで、数万円
   ★免責補償 + NOC + レッカー
   ★名前で選ばない。場所で選ぶ
   　空港より南に泊まる → 空港の近くの営業所
   　空港より北に泊まる → 北側の営業所
   返却は満タン。北へ行くなら名護で給油

06 道(6連発)
   ★沖縄自動車道 = 80km/h
   ★左ミラー。発進前と、左折前
   脇道に車が見えたら、ゆるめる
   雨 + 朝夕 = 線が消える
   ★バスレーン。迷ったら、右の車線
   時間で、車線の向きが変わる

07 渋滞
   ★朝  7:30〜 9:00　那覇へ向かう方向
   ★夕 17:00〜20:00　那覇から北へ向かう方向
   ★ずらす。それだけ
   ★最終日 = 空港の近く(瀬長島・ウミカジテラス)

08 Yナンバー
   Y / A / E = 米軍関係者の車
   事故の流れ ①日本の警察 ②憲兵と通訳 ③同じことを2回
   ★①ぶつからない
   ★②当てられたら: 警察・ナンバー・写真・レンタカー会社

09 距離感
   ★那覇 → 美ら海水族館　片道 約2時間
   ★その日を、"北部の日"にする

10 海 ※テロップは少なく。言葉を聞かせる
   ★白波が立っていない場所が、危ない
   ★流されたら、岸じゃなく、横
   ネットの中で
   素足で岩場を歩かない
   旧盆は、海に入らない

11 持ち帰り
   ★砂・サンゴ・星の砂
   星の砂は、お店で買えます

12 御嶽 ※テロップは最小限。BGMと声で持たせる
   草むらに入らない。それだけ
   ★御嶽(うたき)
   ★香炉・並んだ石・しめ縄 → 引き返す

13 紫外線
   本土の2〜3倍
   日焼けで病院に行く人も
   ★①塗り直す ②曇りこそ注意 ③長袖を1枚

14 天気
   カタブイ = 片方だけ降る雨
   ★カタブイの後は、虹
   台風は、"来る前"に決める
   来たら、ホテルから出ない
   欠航後の振替は、数百人〜数千人待ち

15 お土産
   ★同じものが、スーパーだと安い
   サンエー / かねひで / ドンキ
   安さ → スーパー ／ 種類と手軽さ → 空港 ／ その場で食べる → 国際通り
   17時以降、チャージ料のお店あり
   現金は、多めに
   ★コーレーグースは、数滴

16 旧盆
   旧盆 = 旧暦。毎年、日付が変わる
   "沖縄 旧盆 ○○年" で検索

17 怖がらなくていい
   ハブには、まず会いません
   治安は、いいです
   困ったら、聞いてください
   ★15個、全部――知っていれば防げること

18 まとめ(一覧で一気に)
   ① ホテルは、北部・中部にも
   ② 運転しなくても、回れる
   ③ レンタカーは、補償と、場所で選ぶ
   ④ 80キロ・左ミラー・脇道・雨・バスレーン
   ⑤ 朝7:30と夕5〜8時を避ける。最終日は空港の近く
   ⑥ Yナンバーとは、ぶつからない
   ⑦ 北部の日は、北部だけ
   ⑧ 静かな波が危ない。泳がなくてもいい
   ⑨ 砂とサンゴは、お店で
   ⑩ 草むらと御嶽には、入らない
   ⑪ 曇りでも焼ける。塗り直す
   ⑫ 雨は30分。台風は来る前に決める
   ⑬ お土産は、国際通りで買わなくていい
   ⑭ 旧盆は、調べてから
   ⑮ 怖がらなくていい
```

# 6. BGMと広告のルール

競合動画は、内容ではなく**この2つで苦情が出ていました**。同じ失敗をしないこと。

## BGM

| 幕 | 雰囲気 |
|---|---|
| 01〜05(予約の前に) | 明るめ。軽い |
| 06〜08(ハンドルを握ったら) | 少し緊張感。テンポ |
| **10 海** | **★BGMを止める。波の音だけ** |
| 11 持ち帰り | 静かに戻す |
| **12 御嶽** | **★別の曲に変える。静かで深いもの。音量はさらに下げる** |
| 13〜14(紫外線・天気) | 明るく戻す。虹のところで一番明るく |
| 15 お土産 | 軽快に |
| 16 旧盆 | 静かに |
| **17 怖がらなくていい** | **★一番明るい曲。ここで解放する** |

**音量は、声の1/5以下。** 迷ったら、下げてください。

## 広告(ミッドロール)

手動配置で、**4か所だけ**。**話の途中には絶対に入れない。**

```
① 09:20 の直前 (第1幕の終わり)
② 18:00 の直前 (第2幕の終わり)
③ 24:00 の直前 (第3幕の終わり)
④ 30:30 の直前 (第4幕の終わり)
```

**10 海 と 12 御嶽 の中には、絶対に入れないでください。** 台無しになります。
