### 数字が正直に出せないときの逃げ方

「−5℃」のような数字が出せない題材（ダニなど）では、**盛らない**。
**効果語だけを一段下げ、範囲は下げない。**

- ✅ 家中のダニ**汚れ**が**激減**する ← 効果語だけ下げた
- ❌ **布団**のダニ汚れが激減する ← 範囲まで下げると、クリック率を二重に捨てることになる

## 5. 書き終えたら、必ずこのチェックを通す

**過去に実際にやらかした事故の型。** 全部、一度は「直した」と書いて残っていたもの。

- [ ] **説明の順番と、やる順番が一致しているか**

- [ ] **擬人化した機序を書いていないか**（「ダニが熱を避けて逃げる」→ 正しくは「熱が届かない」）
- [ ] **出典に無い数字を書いていないか**（「二週間で元に戻る」等）
- [ ] **安全上まずい指示になっていないか**
      （電気毛布を布団で包んで放置＝取扱説明書が禁止。**家電は必ず「説明書の表示どおり」に留める**）
- [ ] **道具が要る工程に、逃げ道を付けたか**（「難しい道具もお金もいりません」と言った以上、必須）

- [ ] **尺スクリプトを通したか**（手書きの尺は5回すべて間違っていた）
- [ ] **ブロックを入れ替えたら、シーン番号を振り直したか**
      （入れ替えたまま放置し、本文の並びに対して番号が逆行していた。収録・編集で事故る）
- [ ] **入れ替えで、指示語が宙吊りになっていないか**
      （「その洗濯の話です」の「その」が、入れ替えで50秒前に飛んでいた。「さっき」も同様）
- [ ] **新しく書き足した文を、先に洗い出してA表/B表に当てたか**
      （**事故はいつも「直した箇所の隣に新しく書いた文」で起きる。**追加文だけを先に点検する）
- [ ] **既存の数字を言い換えたとき、単位と対象が変わっていないか**
      （「片面二分」を「端から向こう端まで二分」と言い換えたら、*片面全体*が*1走行*に変わっていた。
      次のシーンが「縦→横」で2走行を求めるので片面4分になり、30秒後の「一枚四分」と破綻した。
      **言い換えた本人には同じに見える。**同じセクション内の他の数字と掛け算して検算すること）

```bash
# ブロックを入れ替えたあとのシーン番号の振り直し（位置だけを見て機械的に）
python3 - <<'PY'
import re, itertools
p='台本/<ファイル名>.md'
t=open(p,encoding='utf-8').read()
i=t.index('## 【'); head,rest=t[:i],t[i:]
j=rest.index('\n## 改稿ログ'); body,tail=rest[:j],rest[j:]   # 改稿ログが無ければこの2行は削る
n=itertools.count(1)
body=re.sub(r'^\*\*S[0-9]+[a-z]?\*\*$', lambda m: f'**S{next(n):02d}**', body, flags=re.M)
open(p,'w',encoding='utf-8').write(head+body+tail)
nums=re.findall(r'^\*\*(S[0-9]+)\*\*$',body,flags=re.M)
print("連番:", nums==[f"S{k+1:02d}" for k in range(len(nums))], f"/ {len(nums)}シーン")
PY
```

> ⚠️ **旧番号→新番号の対応表を作って順に置換してはいけない。**
> 一度そうやって失敗した。置換後の名前が、まだ処理していない旧番号と衝突して本文が壊れる。
> **必ず上のように、位置を見て単一パスで振り直すこと。**

```bash
# 断定を全部抜き出してA表/B表に割り当てる用
python3 - <<'PY'
import re
txt=open('台本/<ファイル名>.md',encoding='utf-8').read()
body=txt[txt.index('## 【'):]
cur=None
for ln in body.split('\n'):
    s=ln.strip()
    m=re.fullmatch(r'\*\*(S[\w]+)\*\*',s)
    if m: cur=m.group(1); continue
    if not s or s[0] in '#|>' or s.startswith('---'): continue
    t=s.replace('**','')
    if re.search(r'ます。|です。|ません。|\d',t): print(f"{cur}: {t}")
PY
```

## 6.5 音声合成（TTS）に通す前の「読み上げ用」の作り方

台本が完成したら、**読み上げ用**を別ファイルで作る。実例: `台本/2026-09_秋のダニ_読み上げ用.md`

> ### 原則: 読みが二つ以上ある語**だけ**、かなに開く。読みが一つの語は漢字のまま。
>
> 最初は「危なそうな漢字を全部かな」にして**71点**だった。
> 読みが一つしかない語（鼻・目・意外・機能・重い・拾い・高評価・視聴）まで開いたせいで、
> **漢字なら起きなかった誤読を新しく作っていた** — 「はなやめに」→花屋、「いがい」→以外、「きのう」→昨日。
> **漢字は、読みが一つなら最強の読み仮名。**

> ### さらに重要: 「開けば安全」ではない。**開いた語が、形態素解析で壊れる。**
> v2で開いた15語を**OpenJTalk（VOICEVOX/COEIROINKの前段）とIPADICに実際に通した**ところ、
> **12語は漢字のままで正読していた**。しかも「よんぷん」は`よん`が**動詞「読ん」**に、
> 「こな」は`こ`＋`な`に、「いちにち」は`いち`＋`に`＋`ち`（動詞）に**分割されて悪化**した。
> **本当に開く必要がある語は、実測で確かめる。**確かめられないなら、漢字のまま。

### 実測で「開く必要がある」と確認できた語（OpenJTalk／IPADIC）

| 語 | 対処 | 実測 |
|---|---|---|
| **方**（〜という方） | **かた** | 漢字はホー。両エンジンで誤読 |
| **二分／四分**（片面で二分） | **`2分`／`4分`／`4分間`（半角算用数字）** | 漢字`二分`は文脈によりニブン。**かな`にふん`は`に`＋`ふん`（感動詞）に割れて平板になる。**算用数字だけが両エンジンでニフン／ヨンプン |
| **叩けば** | **たたけば** | 「叩く」は たたく／はたく の2読みで、**条件形だけハタケバに倒れる**（叩かない・叩いて・叩くはタタ）。実際に誤読した |
| **天日干し** | **てんぴぼし** | 漢字は両エンジンで**テンヒボシ**（濁らない） |
| **十分**（それで十分） | **じゅうぶん** | IPADICで**ジュウフン**。OpenJTalkは正読するが、開いて害はない |
| **後**（〜が後） | **あと** | IPADICで**ゴ**。読点は付けない（「掃除機があと。」） |
| **毛足** | **「毛の長いものほど」に言い換え** | 漢字はIPADICでモウアシ、かな`けあし`は`け`（終助詞）＋`あし`。**言い換えが唯一の全エンジン安全策**。※「毛が長い」は不可（`毛`単独はモー） |
| **もう一手** | **「もうひとつ、手があります」に言い換え** | いって は聞き手にも「行って」と聞こえる |
| **HYPE／YouTube** | ハイプ／ユーチューブ | 英字読み |
| **今日／明日** | きょう／あした | 実測では漢字でも正読。ただし開いて害はなかったので、慣例として開いてよい |
| **効いてはいます**（係助詞「は」＋いる） | **「効いてはいるんです」に言い換え** | 両エンジンで「は」が**ハ**（「はい」が動詞に取られる）。**「〜てはいます」「〜てはいる」の形は全部この罠** |
| **というかた。**（文末） | **「というかたへ。」** | OpenJTalkで**文末の「かた」だけ**か＋た に割れる。「かたは」「かたへ」「かたです」は正常 |
| **細かくなるほど** | **「細かいほど」に言い換え** | 「なるほど」が感動詞に取られ、アクセントの山が消える。「〜になればなるほど」も同じ罠 |
| **舞い上がっているものの正体** | **「物の正体」** | 「ものの」は読点の有無に関係なく**逆接の接続助詞**に取られる |

### 開くと**逆に壊れる**語（実測で確認。漢字のまま）

| 語 | 開くとこうなる |
|---|---|
| **粉** | `こな`が`こ`＋`な`に分割／頭高アクセント。`粉`は両エンジンでコナ acc2（正） |
| **一日／一度** | `いちにち`が`いち`＋`に`＋`ち`に崩壊。`一日`はイチニチ正読。`いちど`は2つのアクセント句に割れる |
| **梅雨** | `つゆ`は**露のアクセント**（acc1）。`梅雨`はOpenJTalkでツユ acc0（正） |
| **鼻／目／意外／機能／重い／拾い／高評価／視聴／相手／一方向／片面** | 同音異義（花・以外・昨日・思い・広い・好評か・市長・開いて・一方）と語境界の誤解析 |

### 手順
