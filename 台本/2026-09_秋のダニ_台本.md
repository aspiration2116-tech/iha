## 設計方針

競合508本にある「ダニ対策7選」は既視感の塊なので、知識の羅列をやめて
**「九月の週末に、この順番で一回だけやる段取り」という手順書**に組み替えている。
尺を賭ける資産は次の二つ。

- **(a) 九月と十月がアレルゲンのピークという季節フレーム**（競合は全て「夏の害虫」文脈）
- **(b) 熱 → 掃除機、という順序でなければ仕上げが空振りになるという論証**

### 守っているルール（過去5回の外部批評で潰した地雷）

| ルール | 理由 |
|---|---|
| 期間は**「九月と十月」で全編統一** | 耳で数字が崩れないため |
| 覚えさせる数字は**「片面一時間」の一つだけ**。合計や五十度・二十分は従属させる | 「ひとつだけ」と宣言した直後に数字を並べると自壊する |
| **段取りの総数（七つ・五つ）を言うのはS15とS87だけ**。途中は「四つ目は布団の外」のように**現在地だけ**を示す | 数の系列が混線すると耳で追えなくなる。ただし現在地を一度も言わないと、七つのどこにいるか分からなくなる |
| 順番を守るのは**「最初の二つだけ」**と正確に言う | 誇張すると回収が期待外れになる |
| 失うものは**「仕上げが空振り」**。「半分」等の量的表現は使わない | 時間比では約6%。数値の誇張になる |
| **根拠のない数字・機序を書かない**（「二週間で元に戻る」「掃除機を避けて奥に潜る」等） | 出典表に対応行がないものは書かない。誤りだった実績がある |
| 「まるごと空振り」の完全形は**S18とS88の二回だけ** | 三回言うと既視感になる |
| **体力への配慮を入れる**。ただし床敷きの布団でも成立する指示にする | タイトルの【60代】と本文を一致させる |
| チャンネル案内は**未回収の問いの直後に置く** | 冒頭に置くと実用開始が遅れ、完結宣言の直後だと離脱点になる |
