## 依頼主の4要求に対して

### ① 構造と設定をもっと作り込む

- **加害の階段**は言葉 → 身につけるもの(通園バッグ) → 金(三十万) → 存在の否定(「お前より、よっぽど母親らしい」)の順のまま。四段とも彩が一度抵抗して潰される形も変えていない。
- **設定の必然性**を作り直した。v1では「訪問看護師である必然」は反転の一点にしか効いていなかった。v2では **彩が三年かよった家 →(空き家)→ 駅前の不動産屋 → 麻衣 → 藤村** という一本の線を張り、麻衣の縁談そのものが彩の仕事から出てくる形にした。加えて、**彩が卒園式に仕事の鞄を持ってきていること**を反転の引き金にした(下の③参照)。
- **共犯者(夫)の「良かった時期」と「変わった時点」**は v1 から置いてある(二晩つきそった病室 / 支店長代理になってから / 「付き合い」が口ぐせ)。v2では締めでこれを鳴らし、さらに**拓に本音を一行だけ**持たせた(「……あの人といると、俺が大きく見えた」)。採点②で「拓に本音の一行が無い(規則3-2)」と引かれていた分。

### ② 伏線とフックを強くする

- 設置と回収の対応表を下に全件出した。**置いただけの伏線は0件**(v1で残っていた腕時計・所長・麻衣の職業を全部回収した)。
- **加害①の鏡**(受け取られなかった手 → 宙に残った腕)はト書きつきで v1 から立っている。v2では**加害②の鏡**(手作りを笑った人に、手で作ったものを彫った男が返す)を足して、二段目を埋めた。
- **コールドオープンは差し替えていない。**藤村「君が言っていた『下の世話』は、この人のことか」がこの台本で一番強い一行で、これより強い行は本文に無い。

### ③ 感情曲線を強くする

- **上げる → 落とす → 上げる**:巾着を縫う(上げ)→ 受け取られない(落とし)→ 娘が「まがってるのがいいの」(上げ)→ バッグを買い替える(落とし)→ 源一「うちが、来てもろうた人だ」(上げ)→ 「お前は来なくていい」(落とし)→ 反転。
- **越えてはいけない一線**は、入院の夜に夫が焼肉屋にいたこと。ここで怒りが確定する。
- **反転は階段**にした。頭を下げる → 「下の世話はこの人のことか」 → **たまたまではない(縁談の出どころ)** → 週に三回 → 母が最後に口にしたもの → **手で作ったものを笑う人だとは** → 拓が氷漬けになる → 麻衣の嘘 → グループの文が読まれる → 記録は持っていない → 麻衣の自爆(三十万) → 彩が立つ。弱い順に出して最後が最強。
- **締めで泣くのは一回だけ**。その直前に無音1.2秒を二つ置いてある。
- **決定的に足りなかったもの(採点8章)への手当て。**v1の反転は藤村・保護者A・麻衣の口という**彩の外**の三つで動いていた。v2は、彩自身の二つの選択を引き金にした。
  - **(a) 手作りのバッグで行かせてください** —— 受諾で出した唯一の条件。これがあるから麻衣は公開の場でバッグを攻撃し、その攻撃の最中に藤村が入ってくる。そして藤村が「手で作ったものを、笑う人だとは」で返す。
  - **(b) 二時から訪問なので、仕事の鞄を持って卒園式に来た** —— 前夜に彩が自分で決めたこと。藤村が最初に見るのは彩の顔ではなく**足元の鞄**で、それは三年間、彼の母の家の上がり口に置かれていた鞄だ(回想のト書きに指定)。締めで藤村が「あの日は、先に鞄が目に入りました」「三年、母の玄関にあった鞄です」と言う。**見下された仕事そのものが、反転を扉から連れてきた形になる。**

### ④ 面白さを足し、無駄を切り、テンポを上げる

- **二度言っている行を削除**:「新しいバッグを、両手で持って歩きました」(直前と同内容)/「縫い目が、一か所だけ曲がっています」(押し入れの場面。次行と同内容)/「最後の半年を、家で過ごすと決めた人です」を静江の台詞と重ならない形に短縮 /「息子さんは遠くにいて、帰るのは月に一度でした」(藤村が反転で言う)/「食べたものが、気管に入る」/「招待の通知だけが、届かない」(直前と同内容)/締めの「食事のあとは、三十分、背中を起こしたまま」(準備と同文)→「今日は、卵焼きを半分。」に差し替え(口から食べる線の回収になる)。
- **説明の地の文を削除**:「そして、深く頭を下げます」→「深く、頭を下げます」/「その日、源一さんが古い体温計をくれました」(台詞とト書きで足りる)。
- **短い一撃**:12字以下 **32%**(基準25%以上)。
- **足したもの**:会場の反応(保護者B「……週に、三回」、ト書きの「保護者が数人、麻衣から半歩離れる」)、加害者の本音一行(拓)、小道具の活用(仕事の鞄を状況説明・回想・前夜・反転・締めの5回)。
