## 0. 先に読む数字(`02_競合分析.md` の実測)

| 要素 | 効果 | 必須か |
|---|---|---|
| タイトルに `♡` | **2.51倍** | **必須** |
| 加害者2人以上 | **2.30倍** | **必須** |
| 妊娠・育児が題材 | 1.84倍 | 優先 |
| 義母**単独** | **0.59倍** | **禁止**(必ず夫や共犯を付ける) |
| 尺17〜19分 | 中央値103,500 | **17分を切らない** |
| 尺17分未満 | 中央値50,000 | 半減する |
| 尺21分以上 | 中央値89,000 | 越えない |
| タイトルの型 | 34/34本で例外なし | **必須** |

**タイトルの型**

```
【漫画】{加害者}「{暴言}ｗ」{共犯者}「{追い打ち}♡」私「{短い受諾}」→{公開の場で}{反転}した結果ｗ【スカッと】
```

- `【漫画】` で始まり `【スカッと】` で終わる(100%)
- `私「〜」` の受けがある(100%)
- `→` で結果を予告(100%)
- `結果` で締める(88%)
- **最初の27字に暴言が入る**(スマホで切れる位置)

**チャプターは作らない。** 上位チャンネルは0。概要欄も短く、伏線を先に割らない。

## 2. 主人公の規則(先生が最も厳しかった点)

1. **企まない。** 証拠は持っているが「お守り」で、使う気はない。
   「三時間座って、帰る。それで終わり」と決めている人が、**嘘をつかれた瞬間に冷える**。
   計画的な復讐は、視聴者が主人公を叩く最大の原因(`02_競合分析.md` §8)。
2. **泣くのは最後の1回だけ。** 困り顔も涙目も禁止。ト書きにも「悲しんでいない」と書く。
3. **受け身にしない。** 加害のたびに一度は抵抗し、**潰される**。抵抗ゼロは「なんで黙ってるの」を呼ぶ。
4. **主人公が金を取り立てない。** 加害者から回収するのは第三者(親族・会社)にやらせる。
   主人公が金を追うと、視聴者の中で主人公が汚れる。
5. **知らないはずのことを知らない。** 自分の式の受付が誰かを「あとで聞く」ような穴を作らない。
   結衣がいない場所の出来事は「ここから先は、人づてに聞いた話です」を先に宣言してから語る。

## 3. 加害者の規則

1. **2人以上。** 主犯 + 同調者。同調者の一言(「母さんの言う通りだよ」)が効く。
2. **本音を一行だけ持たせる。** 「三十七年、窓口係の奥さんと言われ続けたのよ。私は」。
   悪役に厚みが出た瞬間、スカッと度が上がる。**ただし一行だけ**。同情させない。
3. **汎用の悪役語彙を使わない。** 「格が違う」「身の程を知れ」は禁止。
   その人物の生活から出る言葉にする:「油の匂いのする手で、うちの親族と握手させるつもり?」
4. **具体的に失わせる。** 「呼ばれなくなった」だけでは足りない。
   **同じ手口で返す**のが最善(招待状を印刷しなかった女が、法事の案内状を印刷されない)。
5. **財布に一行。** 金を取った側が金を持ったまま終わらない。

## 4. 伏線の規則

- **10組以上、全部回収する。** 置いただけは1件も残さない。
- **設置は状況説明パート**に固める。回収は締めに散らす。
- **最初の加害を最後に鏡で返す。** 加害①と同じ構図・同じ角度で、加害者の側に置く。
  これが「台本の形が円になる」条件。
- **物で見せる。** 「一日中着替えて待っていた」と語らず、「玄関に、モーニングの袋。返却日を、三日過ぎて」と置く。
- **回収の一行に説明を付けない。** 説明した瞬間に、伏線ではなく解説になる。

## 5. 台詞と文体の規則

- **区切り線から区切り線までは、時制をひとつに固定する。** 回想は過去、当日は現在。
  **新しく足した行が、その場面の時制を破っていないか、足した本人が必ず確かめる。**
  ここを怠ると何点でも「録れ」にならない(先生が3回言った)。
- 説明の地の文を書かない。「そして、気づいたのです」「そのときは何のことだかわかりませんでした」は削る。
- 言えない台詞に `「」` を付けない。心の声は地の文で。
- 数字の辻褄を合わせる。見積・差額・負担額・年数は、**視聴者が暗算する**。
- 同じ年数を別の事象に使い回さない(店45年 / 指輪35年 / 恩人40年 / 義母37年)。
- 主語が3行続けて同じにならないようにする。音で聞くと目立つ。

## 6. 機械で落とす(`台本/` のスクリプト)

```bash
python3 njd_check.py      <原稿>        # VOICEVOXの実機と同じ読み。読み事故ゼロが条件
python3 homograph_check.py <原稿>       # 同表記異読語を全件列挙。目視で照合
python3 telop_wrap.py     <原稿> --check # 1行18字・1カード2行を越える文を検出
python3 style_check.py    <原稿>        # 文末連続・セリフ比率・地の文連続・文長分布
python3 telop_wrap.py     <原稿> > <本番用>   # テロップ改行を入れた本番版を出力
```

**合格条件**

| 項目 | 基準 |
|---|---|
| 読み事故 | **0** |
| 同表記異読語 | 全件目視で誤り0 |
| テロップ2行超過 | **0** |
| 13モーラ超のアクセント句 | **0** |
| 文末表現の3連続以上 | **0** |
| 地の文の8連続以上 | **0** |
| 「ました」比率 | 30%以下 |
| セリフ比率 | 50%以上 |
| 12字以下の短文 | 25%以上 |
| 変更表と本文の食い違い | **0**(入れなかったものは「入れなかった」と書く) |

> **新しく書いた行は必ず実機に通す。** 一目→イチモク、方→ホー、君→クン、

## 7. リアリティ(この層が必ず叩く箇所)

40〜60代の主婦層は、**服装・作法・献立・金額・段取り**を見ています。実測コメントで
「グレーのネクタイ!非常識!」(👍54)「振り袖着てる???」(👍26)が上位に来ています。

| 項目 | 規則 |
|---|---|
| 既婚女性の礼装 | 黒留袖。振袖は未婚。**末広は帯に挿したまま。開かせない** |
| 親族でない招待客 | 紋付羽織袴は着せない。濃紺スーツに銀のネクタイ |
| 男性の慶事 | 白または銀のネクタイ |
| 披露宴の受付 | 新郎側・新婦側の友人が一人ずつ立つ |
| 主賓挨拶 | 開宴直後。途中から来た客の挨拶は「祝辞」 |
| 振込人名 | 通帳の記帳では出ない。**銀行の振込明細書** |
| ご祝儀 | 120人×3万=約360万。誰が受け取ったか必ず処理する |
| 季節 | 献立を合わせる(七月にぶり大根は冬の品) |
| 個人店の店主 | 「給料」ではなく「稼ぎ」 |

## 8. 台本ファイルの書式

```markdown
# 台本NN vX「タイトル」
**尺** …  / **読み上げ** …字 / 1文36字以内
## タイトル / ## サムネ
# 台本本文
## 【0:00-0:10】コールドオープン
> ト書き:…
**話者**テキスト
**【無音1.2秒】**
---
# 概要欄
# 制作チェックリスト
```

- 話者名は `**結衣**` のように行頭。地の文も話者(主人公)に持たせる
- ト書きは `> ト書き:` の1行。**マークダウン記法(`**` や `——`)を入れない**(読み上げに乗る)
- 無音は `**【無音1.2秒】**`。区切り線 `---` が場面の切れ目
- 章見出しの時刻は**実測から自動で振り直す**(手で書かない)

## 9. やってはいけないこと(実際にやって直した)

- 「無駄を削れ」を「尺を削れ」と取り違える。**17分未満は再生数が半減する**
- 「1文36字以内」を機械的に守って、全部17字の同じ長さにする。リズムが死ぬ
- 自己申告の変更表に、本文に入れていないものを「入れた」と書く。**直っていないより悪い**
- 先生(レビュアー)の代替テキストをそのまま貼る。**貼った本人が時制と読みを確かめる**
- チャプターを作る / 概要欄で伏線を先に割る
