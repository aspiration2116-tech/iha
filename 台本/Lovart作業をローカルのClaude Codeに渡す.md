# Lovartでの画像生成を、ローカルのClaude Codeにやらせる

クラウド版のClaude Code（claude.ai/code）からは **lovart.ai に接続できない**。
curl も Chromium も、組織の送信プロキシがトンネルを拒否する（`ERR_TUNNEL_CONNECTION_FAILED`）。
**Mac のターミナルで動かす Claude Code には、この制限がない。**

## 手順

1. Mac で、このリポジトリのフォルダに移動して `claude` を起動する
2. 下の枠の中を**まるごとコピーして貼る**
3. ブラウザ操作の許可を求められたら許可する

---

```
Lovartで画像を172枚作ってほしい。

プロンプト: 台本/2026-10_扇風機しまう前_Lovart貼り付け用.txt
　　　　　  1ブロック=1枚。STYLEは展開済みなので、そのまま貼れば動く。
Lovart:     https://www.lovart.ai/canvas?projectId=2pkrisjmr474
　　　　　  （ログイン済みのブラウザを使うこと。未ログインなら私にログインさせず、
　　　　　　 「ログインして」と言って止まってほしい）
モデル:     nanobanana2（無料生成）

## 順番（重要）

1. まず T-01 / T-02 / T-03（サムネ3枚）
2. 次に C003 を作る。これが**人物の基準**。以降、人物が出るカットは
   この画像を参照として渡し、同じ顔にする
3. 次に C007 を作る。これが**扇風機の基準**。以降ずっと同じ個体にする
4. あとは C001 から順番に

人物が出るのはこの18カットだけ:
C003 C005 C019 C026 C031 C055 C056 C062 C064 C083
C091 C106 C129 C142 C146 C149 C163 C167

## 保存

画像/扇風機/C001.png の形式。カット番号そのまま。
サムネは 画像/扇風機/T-01.png。

## 守ること

- **文字が写り込んだ画像は捨てて作り直す。** 日本語は必ず崩れる。テロップは後で乗せる
- **同じ画像を2箇所で使わない。** 使い回しは今回いちばん避けたいこと
- 1カット2〜3枚出して、いちばん良いものを残す

## 進め方

全部で172枚ある。一度に終わらせようとしなくていい。
20枚ごとに、どこまで進んだか教えてほしい。
うまくいかないカットは飛ばして、最後にまとめて報告して。

終わったら:
  python3 台本/画像を点検する.py
を実行して、抜け・重複・使い回しを確認して。
```

---

## 終わったあと

`python3 台本/画像を点検する.py` が出すもの:

- **足りないカット番号**（C001〜C169 / T-01〜T-03）
- **中身が同じ画像**（ハッシュ照合。使い回しの検出＝今回の主目的）
- **極端に小さい／壊れたファイル**
- 台本の対応する文（どのカットが何のシーンか）

画像をgitに入れたあと、クラウド側の私からも同じ点検ができる。

## 補足

- 172枚を一気に作ると無料枠を超える可能性がある。**優先順位は
  サムネ3案 → フック(C001〜C008) → 泥の話(C043〜C058) → 一分版(C064〜C089)。**
  ここまでで動画の勝負どころは埋まる
- Lovartの参照画像機能の名称までは確認していない。見つからなければ、
  生成済み画像を添付して "same person as attached" / "same fan as attached" と添える
