# 競合分析 —— 1番伸びているチャンネルの何が違うか

**調査日** 2026-09-16 / **手法** YouTube InnerTube API による実測(推測を含まない)

---

## 1. 「1番伸びている」の定義を、登録者数ではなく効率で取る

登録者が多い＝伸びている、ではありません。**登録者あたりどれだけ再生を取れているか**で見ます。

| チャンネル | 登録者 | 本数/期間 | 総再生 | **登録者比** |
|---|---|---|---|---|
| **私を甘く見るな【スカッと漫画】** | **4,230人** | 34本 / 3か月 | **450万** | **1,065倍** |
| 逆境よりスカッと | 8,250人 | 36本 / 1か月 | 350万 | 426倍 |
| 噂のスカッと | 41.6万人 | 4本 / 週 | 62万(週) | — |
| トラブルバスターズ | 70.3万人 | 4本 / 週 | 207万(週) | — |
| **スカッと復讐劇場(自)** | **4人** | **5本 / 2か月** | **211** | **53倍** |

**登録者4,230人で450万再生。** これがこのジャンルの本質です。
**登録者は関係ない。**ブラウジング機能と関連動画に刺さるかどうかだけで決まる。
だから登録者4人でも勝てるし、逆に**本数を出さなければ絶対に勝てない**。

## 2. 勝ち筋は2つある。まず、どちらを走るか決める

2位の急伸チャンネルを調べたら、1位とまったく違うモデルでした。

| | **A. 単話型** | **B. 長尺型** |
|---|---|---|
| 代表 | 私を甘く見るな | 逆境よりスカッと |
| 登録者 | 4,230人 | 8,250人 |
| **尺(中央値)** | **18分44秒** | **150分04秒** |
| 尺の範囲 | 15:49〜23:04 | 101:23〜183:56 |
| **投稿間隔** | **2.6日に1本** | **0.8日に1本** |
| 立ち上がり | 3か月で450万 | **1か月で350万** |
| タイトル冒頭 | `【漫画】` | `【スカッとする話】` |
| 需要 | 隙間時間・関連動画 | **作業用・睡眠導入BGM** |

**Bのほうが立ち上がりが速い。**ただし1日あたり2時間半分の台本が必要で、
制作量が桁違いです。

**推奨はA→B。** 単話を書き溜め、20本貯まったら連結して長尺を出す。
Bのチャンネルも中身は複数話の詰め合わせなので、**Aの成果物がそのままBの材料**になります。
いきなりBを狙うと、単話の質が落ちて両方失います。

## 3. 単話型の型は、34本すべてで例外なし

私を甘く見るな 34本の実測:

| 要素 | 遵守率 |
|---|---|
| `【漫画】` で始まる | **34/34 = 100%** |
| `【スカッと】` で終わる | **34/34 = 100%** |
| `私「〜」` の受けがある | **34/34 = 100%** |
| `→` で結果を予告 | **34/34 = 100%** |
| `ｗ` を含む | 33/34 = 97% |
| `結果` で締める | 30/34 = 88% |

```
【漫画】{加害者}「{暴言}ｗ」{共犯者}「{追い打ち}♡」
私「{短い受諾}」→{公開の場で}{反転}した結果ｗ【スカッと】
```

**例外が1本もない。** これは装飾ではなく、ジャンル検索と関連動画に乗るためのシグナルです。

自チャンネルの遵守率は **1/5**。5本目でこの型を外した結果が6回再生でした。

## 4. 同じチャンネルの中で、42万と1.4万を分けたもの

ここが本題です。型を守るのは前提。**その上で何が差をつけたか**。
公開から3週間以上経って伸びきった27本で、タイトル要素ごとに中央値を比較しました。

| 要素 | あり | なし | **差** |
|---|---|---|---|
| **♡ を含む** | 210,000 | 83,500 | **2.51倍** |
| **加害者が2人以上** | 200,000 | 87,000 | **2.30倍** |
| **妊娠・出産・育児** | 160,000 | 87,000 | **1.84倍** |
| 不倫・浮気・愛人 | 120,000 | 94,000 | 1.28倍 |
| **義母・姑・義父** | **59,000** | 99,500 | **0.59倍** |

### ♡ が2.51倍という事実

`ｗ` は加害者の嘲笑、`♡` は**加害者が勝ち誇っている記号**です。
`ｗ` は全員が使うのでもう差がつかない。`♡` はまだ13/34本でしか使われていない。

> 【漫画】義母「高卒の派遣風情が拾ってやったのよ**♡**」夫「母さんの言う通りだよｗ」…… **40万回**

### 加害者2人以上が2.30倍

1人だと「嫌な人がいる」話。2人だと「**囲まれている**」話になる。
視聴者の怒りメーターは、主人公の孤立度で上がります。

### 義母単独は 0.59倍 —— 最激戦区で埋もれている

義母ものは供給過多です。**ただし義母+夫+♡ の組み合わせは40万**を出している。
義母を使うなら、**単独ではなく、夫の同調と ♡ をセットにする**。

### 上位5本と下位5本

```
420,000  妊娠中の私に夫「デ〇妊婦いらんｗ」浮気相手「次は私が産むね♡」
400,000  義母「高卒の派遣風情が拾ってやったのよ♡」夫「母さんの言う通りだよｗ」
380,000  娘より姪っ子が好きな夫「お前も娘もいらん、出てけｗ」
380,000  ママ友「年収2千万の旦那くんの子できちゃった♡」
330,000  夫「妊娠は病気じゃねえよｗ」
─────────────────────────────────
 14,000  夫「カード停止したら離婚なｗ地味な女は捨てるわｗ」  ← 加害者1人・♡なし
 14,000  義母「嫁なんだから無償で当然でしょ♡」            ← 加害者1人・義母単独
 25,000  夫が家族LINEに誤爆「妊娠おめでとう♡」           ← 加害が弱い
```

上位は全部 **♡ あり or 加害者2人以上**。下位は全部 **加害者1人**。

## 5. 尺 —— ここで私は判断を誤っていました

| 尺 | n | 中央値 |
|---|---|---|
| 17分未満 | 3 | **50,000** |
| **17〜19分** | 10 | **103,500** |
| 19〜21分 | 11 | 100,000 |
| 21分以上 | 3 | 89,000 |

**17分未満は半減します。** そしてこのチャンネルは**15分49秒を一度も下回っていない**。

私は「無駄を削れ」という指示を「尺を削れ」と取り違えて、台本を12分55秒まで削りました。
**これは誤りです。** 削るべきは無駄であって、尺ではない。
台本は **16分25秒** に戻し、削った分は効く要素(母の指輪・父の台詞・回想)で埋めました。

## 7. 自チャンネルへの落とし込み

### すぐ直す(今日)

1. **既存5本のタイトルを型に揃える** —— `【漫画】`始まり `【スカッと】`終わり。5本目の誤字も直す
2. **タイトルに ♡ を入れる** —— 加害者が勝ち誇る台詞の末尾に。`ｗ` は共犯者側に
3. **加害者を必ず2人にする** —— 義母+夫、夫+浮気相手、ママ友+取り巻き。**1人の話は書かない**
4. **尺を16〜19分に固定** —— 15分を切らない。21分を超えない

### 次の30日

5. **週4本 × 4週 = 16本。** これが最優先。台本の質より本数が効く段階です
6. **題材の配分を変える** —— 義母単独は0.59倍。
   `夫+浮気相手 6本 / 妊娠・育児 4本 / ママ友・職場 3本 / 義母+夫 3本`
7. **1本ごとに完全独立** —— 後で総集編にするため

### 20本貯まったら

8. **90〜150分の総集編を投入** —— 単話5〜8本を連結。作業用BGM需要を取る
9. タイトルは `【スカッとする話】{一番強い話の見出し}【総集編】`

### 今回の台本への反映(v6で適用済み)

|---|---|
| ♡ が2.51倍 | タイトルの義母の台詞を `呼べないわ♡` に変更 |

| 義母単独は0.59倍 | 義母単独にせず、**夫の出世欲を動機として並走**させた |

## 8. コメント欄の実測 —— ここに「超える」ための答えがある

上位3本のコメントを取得し、**いいね最多のコメントが誰を叩いているか**を見ました。

| 動画 | 再生 | いいね最多のコメント | 矛先 |
|---|---|---|---|
| **披露宴で経歴を明かす** | **40万** | 「よくこんな男と結婚しようと思ったなあ」👍125 | **主人公** |
| 妊娠中に追い出される | 42万 | 「妊娠中の妻を支えるどころか…人として失格」👍130 | 加害者 |
| 娘より姪を優先する夫 | 38万 | 「クソ夫と義姉、反吐が出る」👍118 | 加害者 |

### 視聴者が加害者を叩いていれば成功。主人公を叩いていたら脚本の欠陥

40万を取った**披露宴もの**は、上位コメントが**全部主人公批判**でした。

```
👍125  よくこんな男と結婚しようと思ったなあ。母親もこんなだし。
👍 99  貴方ぐらいのレベルの人が何でこんな駄目男を好きになったんですか。
👍 93  それ以前に、なんであの彼と結婚しようと思ったの？
👍 73  結婚する前に馬鹿丸出しだと思う
👍 68  名家というわりには、息子がダサすぎるし、両親も品が全くない
```

数字は40万出ていますが、**コメント欄は納得されていない**。
「見下される主人公」を描くと、視聴者は必ず**「なぜその男を選んだのか」**を突きます。

**これが、この設定の最大の未解決課題です。** そして上位チャンネルも解けていない。
**ここを解けば超えられます。**

### 解き方(v7で適用済み)

1. **婚約者が「本当に良かった時期」を、行動で描く**
   「優しかった」では足りません。視聴者が見て納得する**一場面**が要る。
   → 父が倒れたとき、**三日間、病院の廊下で寝泊まりした**
2. **いつ変わったかを明示する**
   → **鷹野物産の担当になってから**。「常務」が口ぐせになった
3. **主人公に一度は抵抗させる**
   完全な受け身は「我慢強い」ではなく「馬鹿」に映ります。
   → 指輪を「お断りします」と拒否する。折れるのは**父が止めたから**

### 視聴者はディテールの非常識を叩く

```
👍54  シュンヤさん 結婚式でグレーのネクタイ！非常識！
👍26  ババア、振り袖着てる？？？ 常識は？？？
```

作画の指示に**服装のマナーを明記**してください。

- 既婚女性の第一礼装は**黒留袖**。振袖は未婚女性のもの
- 男性の結婚式のネクタイは**白または銀**。グレー・黒は弔事
- 和装の男性親族は黒紋付羽織袴

### 声の演技が憎らしさを作っている

```
👍41  声優さんには申し訳ないですがクソ夫💢クソ義姉💢
       喋り方がかなり憎々しい💢
```

**「憎々しい喋り方」がコメントを生んでいます。**
義母を WhiteCUL「たのしい」で高く速く喋らせる設計は、この効果を狙ったものです。

### 最も評価された構造は、こちらが採用しているものと同じ

```
👍38  静かに証拠を積み上げて、最後にきっちり現実を突きつける流れが見事で、
       ただ怒鳴るだけ〜
```

**主人公に怒鳴らせず、証拠で逆転する。** この方向は正しい。変える必要はありません。

## 9. 概要欄の型 —— 上位チャンネルは驚くほど短い

34本すべてが**同一のテンプレート**で、変わるのは**一行だけ**です。

```
初めまして！
当チャンネルでは、スカッとできる主婦向け漫画動画を発信しています。

今回は「{一行要約}」をめぐるちょっとスカッとするお話です。   ← ここだけ変わる
「次はこんな話が見たい」があれば、ぜひコメントで聞かせてください。

▼チャンネル登録
@amakumiruna-manga

楽しんでもらえたら、高評価とコメントで反応をもらえると嬉しいです。
制作の大きな支えになります。
─────────────────
当チャンネルの動画はすべてオリジナルで企画・制作したものであり、
無断転載・二次利用はご遠慮ください。
```

判明した3点:

1. **章立て(チャプター)を一切使っていない。** 34本すべて0個
2. **コメント誘導が「次はこんな話が見たい」。** 感想ではなく**企画を出させる**。
   コメント数が増え、同時に次の企画が集まる
3. **無断転載禁止の一文がある。** 他チャンネルの総集編に吸われるのを防ぐため

## 10. この分析でわかっていないこと

正直に書きます。

- **競合の台本本文は取得できていません。** 字幕APIが塞がれているため、
  タイトル・尺・再生数・投稿間隔からの分析です。台本の中身の比較はしていません
- **サムネイル画像も取得できていません。** CTRに最も効く要素を見ていません
- **n=27の中央値比較**です。統計的に厳密な検定はしていません。傾向として読んでください
- 「セリフ比率60%以上」は**当方の設定値で、競合の実測ではありません**
