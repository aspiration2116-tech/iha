## A-1【致命】鷹野の動機が二重で、どちらとも取れる

**該当** L598 / L612 付近

```
L598  鷹野「……健一さんは、来るのか」
      結衣「……いいえ」
      鷹野「そうか」
```

鷹野は**父が招待されていないと知って当日を迎える**。それなのに披露宴でこう聞く。

```
      鷹野「ところで、健一さんは、どちらに?」
      鷹野「私の席から、ご両親のお姿が見えないのですが」
```

知っていて聞いている。**人を公衆の面前で晒す意地の悪い老人に見える。**
四十年前に「いらん。食え」と言われた恩を返しに来た人物として整合しない。

さらに悪いのは **何もしない四十日間**。恩人の娘の式に恩人が呼ばれていないと
知った八十二歳が、父に電話一本かけず、結衣を止めもせず当日を待つ。

### 指示:どちらか一方を選び、台本に明記する

**案A(推奨)── 鷹野は当日まで知らない**

L598〜L602 の3行を削除する。

```
削除  鷹野「……健一さんは、来るのか」
削除  結衣「……いいえ」
削除  鷹野「そうか」
```

「当日は、何も聞かないでください」「気になることがあったら、そのときだけ」
という依頼だけを残す。鷹野は会場で空席を見て、**本当に驚いて**聞く。
これで質問が演技でなくなり、人物が汚れない。
併せて L604〜L608「あの店の飯を四十年食ってきた人間が、ひとりだけ行く /
それでいいんだな / はい」も削除(父が来ないと知っている前提の台詞のため)。

**案B ── 知った上で、結衣に止められている**

L602 の直後に4行を追加する。

```
追加  鷹野「健一さんに、電話していいか」
追加  結衣「やめてください」
追加  鷹野「……なぜだ」
追加  結衣「父に知られたくないんです。私が、しくじったことを」
```

**現状は両案の悪いところ取り。必ずどちらかに寄せること。**
