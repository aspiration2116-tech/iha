## 使い方 —— 台本を書いたら必ずこれを走らせる

```bash
pip install janome
python3 yomi_check.py あなたの台本.md
```

出力は3種類。

| 区分 | 意味 | 対応 |
|---|---|---|
| ① 未知語 | 読みが生成できない語。**確実に事故る** | 辞書登録するか、書き換える |
| ② 危険読み | 既知の誤読パターンに一致した実出力 | 書き換える |
| ③ 固有名詞の分割 | 読みは合うが**アクセント句が割れて棒読みになる** | 辞書登録する |

`✅ 読み事故なし` が出るまで台本を直す。目視チェックは一切しない。

新しい台本で新しい誤読を見つけたら、`yomi_check.py` の `BAD` リストに1行足す。
**チェッカーが台本を書くたびに賢くなる**運用にしてください。

## アクセントについて

### ① 最大の原因は「アクセント句の分割」

現行台本を検査すると、**固有名詞がすべて2トークンに割れています**。

```
東洋通商  → 東洋 + 通商   (6箇所)
みやこ食堂 → みやこ + 食堂 (3箇所)
鷹野物産  → 鷹野 + 物産   (3箇所)
中村結衣  → 中村 + 結衣   (2箇所)
中村健一  → 中村 + 健一   (2箇所)
神崎涼介  → 神崎 + 涼介   (2箇所)
```

読み自体は合っています。**問題はアクセントです。**
2トークンに割れると、VOICEVOXは2つのアクセント句として処理し、
「トーヨー↗ ツーショー↗」と**2回音程が上がる**不自然な読みになります。
人名を呼ぶたびにこれが起きるので、作品全体が素人くさく聞こえます。

**辞書に1語として登録すると、1アクセント句にまとまって解消します。**
つまり辞書登録は「読みを直すため」だけでなく、**アクセントを直すため**にやります。

### ② 辞書登録リスト

VOICEVOX → 設定 → 読み方&アクセント辞書。
入力は「単語 / 読み(全角カタカナ) / アクセント核 / 優先度」。
**アクセント核** = 音が下がる直前のモーラ番号。`0` = 平板(下がらない)。

| 単語 | 読み | 核 | 優先度 |
|---|---|---|---|
| 中村結衣 | ナカムラユイ | 0 | 9 |
| 中村健一 | ナカムラケンイチ | 0 | 9 |
| 結衣 | ユイ | 0 | 9 |
| 健一 | ケンイチ | 0 | 9 |
| 神崎涼介 | カンザキリョースケ | 0 | 9 |
| 神崎政子 | カンザキマサコ | 0 | 9 |
| 涼介 | リョースケ | 0 | 9 |
| 政子 | マサコ | 0 | 9 |
| 鷹野誠一 | タカノセーイチ | 0 | 9 |
| 鷹野 | タカノ | 0 | 9 |
| 鷹野物産 | タカノブッサン | 0 | 9 |
| 東洋通商 | トーヨーツーショー | 0 | 9 |
| みやこ食堂 | ミヤコショクドー | 0 | 9 |
| 黒田 | クロダ | 0 | 9 |
| とん汁 | トンジル | 0 | 8 |
| 日替わり定食 | ヒガワリテーショク | 0 | 8 |
| 主賓 | シュヒン | 1 | 8 |
| 主賓席 | シュヒンセキ | 3 | 8 |

> 長音は必ず **`ー`** で登録する(`セイイチ` ではなく `セーイチ`)。
> `イ` で登録すると母音が二拍に割れて不自然になります。

### ③ 同音異義のアクセント対立(この台本に実在する語)

読みは合っていても、**アクセントを間違えると別の単語に聞こえます**。
辞書登録で核位置を固定してください。

| 語 | 正しい核 | 間違えるとこう聞こえる |
|---|---|---|
| **飴**(アメ) | 尾高 `アメ\` | `ア\メ` = **雨** →「雨をくれた人」になる |
| **箸**(ハシ) | 頭高 `ハ\シ` | `ハシ\` = **橋** / 平板 = **端** |
| **髪**(カミ) | 尾高 `カミ\` | `カ\ミ` = **神** |

### ④ アクセントは機械検証できない —— エディタで必ず目視する

読みは `yomi_check.py` で確定できますが、**アクセントの正誤は
VOICEVOX本体を動かさないと検証できません**(janomeはアクセント情報を持たない)。

書き出し前に、エディタ上で必ずこれをやってください。

1. 全文を流し込み、**アクセント句の区切り線**を上から順に目で追う
2. 人名・社名が**1つのアクセント句にまとまっているか**を確認(割れていたら辞書登録)
3. 「飴」「箸」「髪」の**核の位置**を上表と照合
4. 長い複合名詞(`鷹野物産の代表取締役会長` など)の区切りが自然か確認
5. **通しで聴く。**目と耳の両方を通さない限り、必ず事故が残ります

## 台本を書くときの5原則

| 原則 | 具体 |
|---|---|
| ①固有名詞は**漢字のまま+辞書登録** | カタカナ書きすると読みは直るが**アクセントが平板化して棒読みになる**。辞書側で直す |
| ②危険語は**書き換えで回避** | 辞書は固有名詞専用。一般語は台本側で安全な語に置換するのが速い |
| ③交ぜ書きを恐れない | 「にじんで」「あけたまま」「やむ」「のれん」— 字面より事故ゼロを優先 |
| ④数字は読点で境界を作る | ×`十分前` ○`開宴の、直前` / ×`二十四のとき` ○`二十四歳のとき` |
| ⑤語尾の `?` は**全角** | 疑問イントネーションが付く。半角 `?` は付かない |

### 記号の扱い

`ｗ` `♡` `──` `……` は**すべて無音で、間(ま)にもなりません**。
本文に書いても効果ゼロです(タイトル・サムネにはOK)。

間は「、」「。」と**行分割**でのみ作れます。
標準ポーズは 読点≒0.15秒 / 句点≒0.35秒。
それ以上の間が必要な箇所は、**その行を単独の音声ファイルにして編集で無音を挿入**します。

## 話者設計

### ずんだもんを使うべきか

**本編ナレーションには使わない。**

- 基本周波数が高く語尾が跳ねる設計で、**15分の重い話を聴かせる持久力がない**
- 「〜のだ」口調の刷り込みが強く、シリアスな一人称と視聴者の中で衝突する
- ただし**ショート動画・チャンネルのマスコット・予告**では圧倒的に強い(認知度が最大のVOICEVOX話者)。本編と役割を分ける

### 本作の割り当て

| 役 | 話者 / スタイル | 速度 | 高さ | 抑揚 | 意図 |
|---|---|---|---|---|---|
| 結衣(主人公・地の文) | 九州そら / ノーマル | 1.05 | 0.00 | **0.90** | 抑揚を落として「感情を殺している人」を作る。ラストの1箇所だけ抑揚1.05に戻す |
| 政子(義母) | WhiteCUL / たのしい | 1.10 | **+0.03** | **1.15** | 高く速く。悪意を「楽しそうに」喋らせるのが最も不快 |
| 涼介(婚約者) | 青山龍星 / ノーマル | 1.00 | 0.00 | 0.95 | |
| 鷹野(82歳) | 玄野武宏 / ノーマル | **0.88** | **-0.04** | 0.85 | 遅く低くすると年齢が出る |
| 健一(父) | 玄野武宏 / ノーマル | 0.92 | **-0.02** | 0.90 | 鷹野と同話者。速度差0.04以上を必ず付けて聴き分けさせる |
| 黒田・プランナー・司会 | 白上虎太郎 / ふつう | 1.00 | 0.00 | 1.00 | |

**唯一の演出上の例外**:ラスト「そこで初めて、私は、泣きました」の前後だけ、
結衣の抑揚を `0.90 → 1.05`、速度を `1.05 → 0.95` に変える。
全編で感情を殺してきた声が、ここだけ揺れる。これが効きます。
