# VOICEVOX 読み・アクセント事故ゼロ運用マニュアル

## なぜ事故るのか(仕組み)

VOICEVOXの読み推定は **OpenJTalk + NAIST-jdic** です。挙動の癖を知らないと必ず事故ります。

1. **未知語はカタカナ分解される** — 辞書にない固有名詞は漢字の音読みに分解され、アクセントは「複合語アクセント規則」で**後部要素の型に引っ張られる**。人名が全滅するのはこれ。
2. **同表記異音は文脈ではなく品詞で決まる** — 「通って(カヨッテ/トオッテ)」「吐く(ハク/ツク)」は、前後の意味ではなく**形態素解析の結果**で決まる。前後関係で直せると思ってはいけない。
3. **文頭の「今日は」は挨拶として学習されている** — 「本日は」に書き換える以外に確実な回避策がない。
4. **数詞+助数詞は形態素境界が曖昧なときに壊れる** — 「十分前」が代表例。**読点を打つと境界が確定して直ることがある**。
5. **記号は読まれない** — `ｗ` `──` `……` `♡` はすべて無音。**間(ま)の制御には使えない**。間は「、」「。」と行分割でのみ作る。

## 台本を書くときの5原則

| 原則 | 具体 |
|---|---|
| ①固有名詞は**漢字のまま+辞書登録** | カタカナ書きすると読みは直るが**アクセントが平板化**して棒読みになる。必ず辞書側で直す |
| ②危険語は**書き換えで回避**(辞書に頼らない) | 辞書は固有名詞専用。一般語は台本側で安全な語に置換するのが速い |
| ③交ぜ書きを恐れない | 「背すじ」「にじんで」「あけたまま」「やむ」— 字面より事故ゼロを優先 |
| ④数字は読点で境界を作る | ×「十分前」 ○「開宴の、直前」/ ×「二十四のとき」 ○「二十四歳のとき」 |
| ⑤語尾の「?」は**全角**で入れる | 疑問イントネーションが付く。半角`?`は付かない |

## 辞書登録リスト(VOICEVOX → 設定 → 読み方&アクセント辞書)

入力欄は「単語 / 読み(全角カタカナ) / アクセント核 / 優先度」。
**アクセント核**=音が下がる直前のモーラ番号。`0`=平板(下がらない)。

## 話者設計

### ずんだもんを使うべきか

**結論:このジャンルの本編ナレーションには使わない。**

- ずんだもん(ノーマル)は基本周波数が高く、語尾が跳ねる設計。**18分の重い話を聴かせる持久力がない**
- 「〜のだ」口調の刷り込みが強く、シリアスな一人称と視聴者の中で衝突する
- ただし**ショート動画・チャンネルのマスコット・予告**では圧倒的に強い(認知度が最大のVOICEVOX話者)。本編とは役割を分ける

### 本作の話者割り当て

| 役 | 話者 / スタイル | 速度 | 高さ | 抑揚 | 意図 |
|---|---|---|---|---|---|
| 結衣(主人公・地の文) | 九州そら / ノーマル | 1.05 | 0.00 | **0.90** | 抑揚を落として「感情を殺している人」を作る |
| 政子(義母) | WhiteCUL / たのしい | 1.10 | **+0.03** | **1.15** | 高く速く。悪意を「楽しそう」に喋らせるのが最も不快 |
| 涼介(婚約者) | 青山龍星 / ノーマル | 1.00 | 0.00 | 0.95 | |
| 鷹野(82歳) | 玄野武宏 / ノーマル | **0.88** | **-0.04** | 0.85 | 遅く低くすると年齢が出る |
| 大吾(父) | 玄野武宏 / ノーマル | 0.92 | **-0.02** | 0.90 | 鷹野と同話者だが速度・高さで差を付ける |
| 黒田常務・プランナー・司会 | 白上虎太郎 / ふつう | 1.00 | 0.00 | 1.00 | |

> 父と会長を同じ話者で作るときは、**速度差0.04以上**をつけないと聴き分けられない。

### 間(ま)の作り方

VOICEVOXの標準ポーズは 読点≒0.15秒 / 句点≒0.35秒。台本上の `──` `……` は**一切読まれず、間にもならない**。

- **1秒の間**が欲しい → その行を単独の音声ファイルにして、編集で無音1秒を挿入
- **0.7秒程度** → 句点だけの短い行を挟む(例:「音が、消えました。」を1行で独立させる)
- **畳みかけ** → 読点を打たずに一息で書く

本作で**必ず無音を入れる3箇所**:

1. 鷹野「大吾さんは、どちらに?」の直後 → **無音1.2秒**
2. 結衣「――中村、大吾」の直後 → **無音1.5秒**
3. 鷹野「……いい手だ」の直後 → **無音1.0秒**
