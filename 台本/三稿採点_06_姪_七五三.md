**判断は誤りだ。ただし理由の半分は正しい。**

正しい部分:マニュアル1章が「私がなぜそれを笑って受け入れたのか。最後まで、ご覧ください」を**型として指定している**。
これを崩して混在を消すのは本末転倒だ。**その読みは正しい。**

誤っている部分:**「型を壊す」か「混在を残す」かは、二択ではない。**

`endings.py` は `---` / `> ト書き` / `## ` で区切りを切る(ソース確認済み)。
**L265 の次に `---` を一本入れるだけでいい。**私が実際に試した:

```
区切り 2  【0:15-0:35】約束        ← 過去のみ
   —    会食の、三週間前。
   過去  私は夫と義姉から、こう言われました。

区切り 3  【0:35-2:35】状況説明     ← 現在のみ
   —    私がなぜ、それを笑って受け入れたのか。
   現在  最後まで、ご覧ください。

区切り 55 / 時制が混在 0。
```

**0秒・0字・型は一語も変わらない。**
しかも構造として正しい。L261-263 は**台所の場面の予告**(過去の出来事の紹介)、
L267-269 は**視聴者への口上**だ。マニュアル8章は `---` を「場面の切れ目」と定義している。
**ここは場面の切れ目だ。**

「入れなかったものは入れなかったと書く」を守ったのは良い。
**だが、入れられるものを入れなかったのは、正直さではなく不足だ。**
残すと決める前に、**残さずに済む道が本当に無いかを一度試す。**
