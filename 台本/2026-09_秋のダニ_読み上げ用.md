## 方針（v2で改めた）

> **読みが二つ以上ある語だけ、かなに開く。読みが一つしかない語は、漢字のまま。**

v1は「危なそうな漢字を全部かなに」していたが、専門レビュー（71点）で
**読みが一つしかない語まで開いたせいで、漢字なら起きなかった誤読を新しく作っていた**と判定された。

| v1で開いていた語 | 起きた副作用 |
|---|---|
| 鼻や目に → はなやめに | 「**花屋**、めに」と語境界を誤解析。「はな」は**花**のアクセントになる |
| 意外 → いがい | **以外**（より高頻度）で読まれる |
| 機能 → きのう | **昨日**で読まれる |
| 重い → おもい | **思い**で読まれる |
| 拾いきれない → ひろいきれない | **広い**で読まれる |
| 高評価 → こうひょうか | 「**好評**か、と」に切れる |
| ご視聴 → ごしちょう | **市長**のアクセント |
| 一方向 → いっぽうこう | 「**一方**、こうだけだと」に切れる |
| 日の当たる → ひのあたる | **火**で読まれる |
| 週に二回 → しゅうににかい | **二階**で読まれる |
| 相手は → あいては | 「**開いて**は」 |

**漢字は、読みが一つなら最強の読み仮名。**開くのは本当に揺れる語だけにする。

### 漢字のまま残した語（かなにすると逆に危ない）

日（晴れた日・日の当たる・日をまたぐ）／鼻／目／意外／機能／重い／拾い／高評価／視聴／下／側／相手／一方向／片面／両面／
中・中身／生きた・生き物／表面・表示／九月・十月／一時間／五十度／二十分・三十分／三か月・四か月／一枚／一円／三回／
二か所・三か所／一つ目・二つ目・三つ目／洗濯機／布／羽根／考え方／肩

> **「洗濯機」**はエンジンが自然に「せんたっき」または「せんたくき」と読む。v1で「せんたっき」と強制していたが、
> 未知語扱いで一音ずつ平板に読まれるエンジンがあるため、漢字に戻した。

### 記号・間の作り方

- 「──」「……」「〇〇」は使わない（「ダッシュ」「てんてん」と読むエンジンがある）。間は「、」と「。」だけ。
- **大きな間は行を分けてある。**次の3か所は行間で1秒以上空けること:
  **S24→S25**（「治まるでしょうか。」→1.5秒→「治まりません。」）／**S60**（「意外に思われます。」→1秒→「ぬいぐるみです。」）／**S66**（「今日のコレ。」→1秒→「熱をかけてから」）
- 語境界を誤解析しやすい箇所には読点を足した（「こう、考えて」「入れて、口を」「奥に、入り込んだ」など）。
  逆に、**読点を入れると意味が変わる箇所は入れていない**（「舞い上がっているものの正体は」— 読点を打つと「ものの」が逆接になる）。
