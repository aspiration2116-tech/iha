# 健康コーチ

食事・体重・血圧・睡眠を1か所に記録して、その日にやることを出すローカルツール。
外部ライブラリなし・通信なし（127.0.0.1 でしか待ち受けない）。データは `coach.db` にだけ入る。

> **これは医療機器でも診断ツールでもありません。** 表示される数値・判定はすべて一般的な目安で、
> 個人の状態に合わせたものではありません。持病・服薬がある場合、血圧の高い状態が続く場合、
> 体調に不安がある場合は必ず医師に相談してください。自己判断で薬をやめたり量を変えたりしないこと。

## 使いはじめ

```bash
python3 coach_server.py      # → http://localhost:8771
```

Mac ならリポジトリ直下の `健康コーチ.command` をダブルクリックでも起動する。

### まとめて記録

食事・運動・体重・血圧・睡眠・歩数を**1行に混ぜて**書けます。画面の「今日」タブ
いちばん上の入力欄か、端末から:

```bash
python3 coach.py log "朝 ご飯 納豆 味噌汁 昼 ラーメン 汁残し 体重 98.4 血圧 138 88 睡眠 0:30-6:40 三頭筋 3x50 8000歩"
```

書き方の目安（順番も区切りも自由。読めたものだけ記録して、残りは「分からなかった」と表示）:

| 書き方 | 例 |
|---|---|
| 食事 | `朝 ご飯 納豆 味噌汁` `昼 ラーメン` `間食 サラダチキン` |
| 量を変える | `ご飯x1.5` `鶏むね肉 皮なしx2` |
| 表にない食品 | `社食の日替わり700kcal` |
| 食べ方 | `ラーメン 汁残し` … 汁を残した版（塩分が約3g減る）で記録 |
| 筋トレ | `三頭筋 3x50` `レッグプレス 3x12 80kg` `腹筋 50回` |
| 有酸素 | `トレッドミル 20分` `バイク 30分` |
| 体重・体組成 | `体重 98.4` `体脂肪 35.2` `筋肉量 60` |
| 血圧 | `血圧 138 88` `138/88 脈72` |
| 睡眠 | `睡眠 0:30-6:40` |
| 歩数 | `8000歩` |

種目は略称でも通ります（三頭筋・腹筋・脚・背中・胸・肩・ベンチ・デッド など）。

### そのほかの端末コマンド

```bash
python3 coach.py today          # 今日の状況とコーチング
python3 coach.py plan           # 目標カロリーと到達見込み
python3 coach.py weight 98.4    # 体重を記録
python3 coach.py bp 138 88 --slot 朝
```

**最初にやること**: 身長・体重・年齢・性別を自分の値にする。2通り。

- 「設定」タブで入力する（`coach.db` に入る。gitには含まれない）
- `profile.example.json` を `profile.json` にコピーして書き換える（gitには含まれない）

初期値は 170cm / 80kg / 40歳 のプレースホルダで、ここが違うと必要カロリーが1割以上ずれる。

> **このリポジトリは公開設定です。** 体重・血圧・体脂肪率などの記録は
> `coach.db` と `profile.json` に入り、どちらも `.gitignore` に入れてあるので
> コミットされません。身体の数値をリポジトリに書き足さないでください。

## 数値例（身長175cm・95kg・45歳・目標75kg の場合）

説明用の例です。自分の値を入れれば全部再計算されます。

| | 値 |
|---|---|
| BMI | 31.0（肥満2度）→ 目標75kgで 24.5 |
| 基礎代謝 | 1,824 kcal |
| 1日の消費 | 2,371 kcal |
| **目標摂取** | **1,820 kcal** |
| たんぱく質 | 98 g |
| 脂質 / 炭水化物 | 51 g / 242 g |
| 食塩 | 6 g 未満 |
| ペース | 週 約0.54kg |
| 到達見込み | 約9.2ヶ月 |

**この期間は遅く見えるが、これが最短に近い。** 体重が落ちると基礎代謝も下がるので、
後半ほどペースは鈍る（週ごとに再計算して織り込んである）。もっと速いペースを設定しても、
摂取カロリーは**基礎代謝を下回らないところで自動的に止まる**。それ以下にすると
体重は一時的に速く落ちるが、減るのは筋肉で、代謝が落ちてほぼ確実に戻る。

## 体組成を入れると計算が変わる

「今日」タブで体脂肪率か筋肉量を入れると（体組成計の値、月1回で十分）、
除脂肪体重と体脂肪量を出して計算に使う。

例：**体重95kg・筋肉量58kg** の場合 → 除脂肪体重 61.3kg / 体脂肪 33.7kg（35.4%）

- **たんぱく質の目標**が「目標体重×1.5g」から「除脂肪体重×1.6g」に切り替わる
- **基礎代謝**に Katch-McArdle 式（除脂肪体重ベース）が選べるようになる。
  ただし家庭用の体組成計は体脂肪が多いほど筋肉量を多めに出しやすいので、
  迷うなら Mifflin のまま（低めに見積もって食べなさすぎるのを防げる）
- **プラン**タブに「目標体重に着いたときの体脂肪率」の表が出る。
  同じ70kgでも、途中で除脂肪をどれだけ守れたかで中身がまったく変わる

| 減量中に失う除脂肪 | 75kg時の除脂肪 | 体脂肪率 |
|---|---|---|
| 0%（理想） | 61.3kg | 18.3% |
| 10%（うまくいった場合） | 59.3kg | 20.9% |
| 20%（ふつう） | 57.3kg | 23.6% |
| 30%（たんぱく質・筋トレ不足） | 55.3kg | 26.3% |

これがたんぱく質と筋トレをやる理由。**体重が同じなら、見た目を決めるのは体脂肪率のほう。**
落とす体重が大きいほど、この差も大きくなる。

## 筋トレについて

減量中の筋トレは「筋肉を増やす」ためではなく、**落ちる体重の中身を脂肪に寄せる**ため。
カロリーが足りない状態で筋肉はほとんど増えないので、重量が伸びなくても役目は果たしている。

- **大きい筋肉（脚・背中・胸）を先に。** 使う筋肉の量が桁違いで、消費カロリーも
  筋肉を守る効果も大きい。腕・腹は補助
- **腹筋をいくらやってもお腹の脂肪は落ちない**（部分やせは起きない）。
  お腹を凹ませるのは腹筋運動ではなく体脂肪を減らすこと
- 週2〜3回、1回45分。A日（脚＋腹）とB日（背中＋胸＋腕）を交互に、同じ部位は48時間あける
- **血圧が高いときはいきまない。** 息を止めて力むと血圧が大きく跳ね上がる。
  ①息を止めない ②1セット10回以上できる重さ ③セット間は十分休む

アプリは直近7日で大筋群をやれているかを見て、小さい筋肉だけになっていると指摘する。

## やる順番

一度に全部やろうとすると必ず失敗する。効く順ではなく、**続く順**に並べてある。

**第1〜2週：測るだけ。制限はしない**
毎朝の体重（起床後トイレのあと、下着）、食べたもの全部、朝晩の血圧、就寝と起床。
ここで「今どれだけ食べていて、どれだけ塩を取っているか」が分かる。
この2週間を飛ばすと、あとで停滞したときに何を直せばいいか判断できなくなる。

**第3〜4週：起床時刻の固定と減塩**
起床を毎日同じ時刻に（休日も±1時間以内）。起きて1時間以内に日光を15分。
麺類の汁を残す、醤油・ソースは小皿でつける。カロリーはまだ緩くていい。
この2つだけで睡眠と血圧が動き始める。

**第5週〜：目標カロリーとたんぱく質**
毎食に手のひら1枚分のたんぱく質（肉・魚・卵・豆腐）、主食は測って盛る。
同時に週150分の早歩き（10分×3回に分けても効果は同じ）。

**停滞したら**（2〜3週間動かないのは正常）
①記録漏れを疑う（油・ドレッシング・飲み物・つまみ食い）→ ②体重が減った分だけ
目標カロリーが下がっているか確認 → ③塩分と便通による水分 → ④活動量。
①が当たることが一番多い。食事をさらに削るのは最後の手段。

## 血圧について

家庭血圧は **135/85 mmHg 未満**が目標（診察室で測る場合は140/90）。
家庭で測った値のほうが診断の精度は高いとされている。

測り方：朝は起床後1時間以内・トイレのあと・朝食と薬の前。晩は就寝前。
背もたれのある椅子に座り、腕帯を心臓の高さにして1〜2分安静にしてから測る。
**1回の値ではなく平均で判断する。**

効く順：
1. **減塩**（1日6g未満）— 麺の汁を残すだけで2〜3g減る。食塩1g減で上の血圧が約1mmHg下がる目安
2. **減量** — 体重1kg減で上の血圧が約1mmHg下がる目安。落とす量が大きいほど効く
3. **有酸素運動**（週150分の早歩き）
4. **節酒** — 飲酒量に比例して血圧は上がる。減らすと数日で下がり始める
5. **カリウム**（野菜・果物・海藻・大豆）— ただし**腎臓の病気がある人・カリウムを上げる薬を
   飲んでいる人は自己判断で増やさない**

受診の目安（アプリが自動で出す）:
- 180/110 以上 → 測り直しても高ければ様子を見ずに受診
- 160/100 以上 → 数日以内に受診
- 家庭血圧の平均が 135/85 以上のまま2週間 → 受診の予約

「血圧」タブから家庭血圧の記録をCSVで書き出せる。受診時に持っていくと診断と薬の調整に直接使える。

## 睡眠について

睡眠不足は食欲ホルモン（グレリン↑・レプチン↓）を動かして翌日の食欲を増やす。
**減量の足を直接引っ張るので、食事より先に直す価値がある。**

土台は3つ、この順で:
1. **起床時刻を固定する**（就寝時刻ではなく）。体内時計は起床で決まる
2. **朝の光**。起きて1時間以内に15分。光を浴びた14〜16時間後に眠気が来る
3. **カフェインは14時まで**。半分抜けるのに5〜6時間かかる

そのあとに、寝酒をやめる／夕食を就寝3時間前まで／就寝1時間前は画面を見ない／
就寝90分前に入浴／眠れないとき15分以上ふとんで粘らない。
アプリの「睡眠チェック」9項目がこの順に並んでいる。**上から1つずつ2週間かけて定着させる。**

### 睡眠時無呼吸（SAS）— 最初に確認してほしいこと

BMIが高く血圧も高い場合、**睡眠時無呼吸がその両方の原因になっていることがある。**
あると、何時間寝ても疲れが取れず、食事と運動を頑張っても血圧が下がりにくい状態が続く。
逆に治療すると睡眠も血圧も一気に改善することがある。

アプリは STOP-BANG 質問票に準じた8項目（いびき／日中の眠気／呼吸停止の指摘／高血圧／
BMI35超／50歳超／首まわり40cm超／男性）で判定し、3項目以上で受診をすすめる。
**これはあくまで受診の目安で、診断ではない。**
検査は自宅で一晩の簡易検査ができる（呼吸器内科・睡眠外来・耳鼻咽喉科）。

ダイエットより先に、ここを一度調べる価値がある。

## 判定ロジックの根拠

| 項目 | 使っている基準 |
|---|---|
| BMIの分類 | 日本肥満学会の判定基準 |
| 基礎代謝 | Mifflin-St Jeor 式（体組成を記録していれば Katch-McArdle 式も選べる） |
| 身体活動レベル | 1.30 / 1.45 / 1.60 の3段階 |
| 減量ペース | 週0.5〜1.0%（体脂肪1kg = 7,200kcal で換算） |
| 摂取の下限 | 基礎代謝、かつ男性1,500 / 女性1,200 kcal。赤字はTDEEの25%まで |
| たんぱく質 | 除脂肪体重 × 1.6g。体組成が未記録なら目標体重 × 1.5g（最低90g） |
| 脂質 | 総カロリーの25% |
| 食塩 | 6g未満（日本高血圧学会の減塩目標） |
| 家庭血圧の分類 | 高血圧治療ガイドライン2019 の家庭血圧基準 |
| 睡眠時無呼吸 | STOP-BANG に準じた簡易版 |
| 睡眠の習慣 | 不眠症の認知行動療法（CBT-I）と睡眠衛生指導で使われる項目 |
| 除脂肪体重 | 体脂肪率があればそこから。筋肉量のみの場合は骨量を体重の3.5%として概算 |

数値は一般的な目安であり、個人差がある。腎機能に問題がある場合はたんぱく質・カリウムを
自己判断で増やさないこと。

## 中身

```
coach.py          計算とコーチング判定、CLI
coach_server.py   ローカルサーバー（標準ライブラリのみ、127.0.0.1 のみ）
coach.html        ダッシュボード（依存ライブラリなし、グラフも自前のSVG）
foods.json        食品192品目。kcal / P / F / C / 食塩相当量
coach.db          記録（初回起動時に自動生成。gitには入らない）
profile.json      自分の身体の値（任意。gitには入らない）
profile.example.json  上のひな形
```

食品の値は日本食品標準成分表および市販品の一般的な表示値をもとにした**1単位あたりの概算**で、
商品により差がある。正確さより**漏れなく入れること**のほうが結果に効く。
