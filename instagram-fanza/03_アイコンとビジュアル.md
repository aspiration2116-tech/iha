# 03. アイコンとビジュアル

## アイコン3案

`icons/preview.html` をブラウザで開くと、150px / 88px / 40px / 28px の**円形クロップ**で3案を比較できる。

| 案 | ファイル | 性格 |
|---|---|---|
| A | `icons/icon-a-yorunohonya.png` | 夜＋積み本。参考アカウント（ヨルノホンヤ）に一番近い王道 |
| B | `icons/icon-b-logo.png` | 「同」の一文字ロゴ。小サイズでの識別性が最強 |
| C | `icons/icon-c-neko.png` | ネコ司書。親しみ重視、リール内のマスコットに流用できる |

**選び方は1点だけ**：28px（コメント欄サイズ）に縮めても「これだ」と分かるか。
迷ったら **B案**。フィードでの視認性が最も高く、ジャンル説明は表示名とbioが担うので、
アイコンは「識別できること」に全振りしてよい。

## 色を変える

SVGはテキストなので、色コードを書き換えるだけで作り直せる。

```bash
cd icons
sed -i '' 's/#F6C963/<新しい色>/g' icon-a-yorunohonya.svg   # ゴールド部分
```

書き出し（PNG化）は Chrome があればコマンド1本でできる。

```bash
# macOS の場合
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --hide-scrollbars --window-size=1080,1080 \
  --screenshot=icon-a-yorunohonya.png \
  "file://$PWD/icon-a-yorunohonya.svg"
```

うまく余白が入る場合は、`preview.html` の隣に置いたSVGをブラウザで開いてスクリーンショットでも十分（Instagram側で縮小されるため）。

## ブランドカラー（3案共通で使える）

| 用途 | 色 | 使いどころ |
|---|---|---|
| 背景（濃） | `#141B44` | リールの外枠・帯 |
| 背景（淡） | `#F3E9D2` | テキストカードの地 |
| アクセント | `#F6C963` | 「作品名はこちら」など行動を促す部分だけ |
| サブ | `#E97C7C` | ジャンルタグ、ハートなど |

**アクセント色は1画面に1箇所**。参考アカウントで黄色い帯（作品名はスクショしてQR長押し）が効いているのは、
画面内で黄色がそこにしかないから。

## リールのカバー（サムネ）の型

参考アカウントの構造をそのまま流用できる。上から:

```
┌──────────────────────────┐
│  ①煽りテキスト（黒・極太・2行以内）    │  ← 画面上部15%。フィードで最初に読まれる
├──────────────────────────┤
│  ②誘導帯（黄）      ③QR / 記号      │  ← 「作品名はプロフィールから」
├──────────────────────────┤
│                              │
│  ④本編（4コマ風・モノトーン加工）    │  ← 全年齢で成立する画だけ
│                              │
├──────────────────────────┤
│  ⑤再生数風の数字 / マスコット        │
└──────────────────────────┘
```

- ①のフォントは **極太ゴシック**（源ノ角ゴシック Heavy / ヒラギノ角ゴ W8）。細字は縮小で消える
- カバーは**フィード用（1:1）で切れない位置**にテキストを置く。リールは9:16だが一覧は1:1で切られる
- ②の帯は毎回同じ位置・同じ文言にする。回遊してきた人が学習する

## ハイライトカバー

`icons/` のアイコンの背景色（`#141B44`）に、白い線画アイコンを1つ置いただけのものを4枚作る。
文字は入れず、名前（「はじめに」等）はハイライトのタイトルで表示させる。
Canva の「Instagram ストーリーズ」テンプレで10分で作れる。
