# 04. 投稿テンプレート

## 先に、画像の権利の話

参考アカウントは漫画のコマをそのまま貼っているが、**あれは権利者の許諾がなければ著作権侵害**であり、
出版社の申し立て一発でアカウントが消える。同人作家は個人なので通報が直接飛んでくる。真似しない。

安全にやれるのは次の3つ。

1. **DMMアフィリエイトが提供する素材**（管理画面のバナー・API経由の商品画像）を、規約の範囲で使う
   → ただしFANZA同人のサンプル画像は成人向けなのでInstagramには出せない。**使えるのは全年齢作品のみ**
2. **自作のテキストカード**（あらすじ・セリフ引用の範囲・感想）
   → 引用は「主が自分の文章、従が引用」「出典明記」が条件。実質これがメイン戦力
3. **自分で描く / 依頼したイラスト**

つまりこのアカウントの投稿の中心は **「文字と構成で読ませるリール」** になる。
画像を持ってこられない代わりに、テキストの企画力で戦う形。これは実際に成立する（書評・映画紹介系と同じ型）。

## リールの基本構成（15〜25秒）

| 秒数 | 内容 | 注意 |
|---|---|---|
| 0.0〜1.5秒 | **フック1行**（例: 「読み終わって声が出た同人、あります」） | ここで9割が離脱する。最重要 |
| 1.5〜5秒 | 状況設定（「幼なじみが、他人の名字で呼ばれてた」） | 具体名詞を入れる |
| 5〜15秒 | 展開を3〜4カット。**結末は言わない** | 1カット2〜3秒。文字は1画面20字以内 |
| 15〜20秒 | 「続きは自分で読んでほしい」＋**作品名はプロフィールから** | 毎回同じ文言・同じ位置 |
| 全編 | BGMはトレンド音源（Instagram内で「人気」表示のもの） | 音源選びで初速が2〜3倍変わる |

## 9本の初期ストック（型を分けて計測する）

1. 感情フック型 …「読み終わって10分動けなかった」
2. シチュエーション型 …「両片想いが好きな人にだけ教えたい」
3. ランキング型 …「今月読んだ中で上から3つ」
4. 比較型 …「甘いのが好きな人／苦いのが好きな人」
5. あるある型 …「同人買うとき、ここ見て選んでる」
6. 質問型 …「これ、どっちが好き？」（コメント狙い）
7. 初心者向け型 …「同人ってどこで買うのが正解？」
8. 作家紹介型 …「この人の絵、見たら分かる」
9. まとめ型 …「保存しておくと後で助かるやつ」

**保存数（Save）が伸びた型を翌月に量産する。**いいね数ではなく保存数を見る。

## キャプション雛形

```
{フックの言い換えを1行}

{2〜3行の紹介文。ネタバレなし。「誰に刺さるか」を書く}

作品名はプロフィールのリンクからまとめて置いてます📚
気になったら保存して、あとでゆっくりどうぞ。

────────
毎日21時、ひとつだけ紹介しています
@{アカウント名}

#同人誌 #同人漫画 #漫画紹介 #おすすめ漫画 #マンガ好きな人と繋がりたい
#読書記録 #漫画好きと繋がりたい #マンガ紹介 #創作漫画 #電子書籍
```

- 1行目は**フックの繰り返しではなく言い換え**にする（同じ文だと機械的に見える）
- 「保存して」は明示的に入れる。言うと実際に保存率が上がる
- @メンションで自アカウントを入れるとプロフィール遷移が増える

## ハッシュタグの方針

- **10〜15個**。30個は逆効果（スパム判定されやすい）
- 露骨なタグ（成人向けワード）は**絶対に入れない**。タグ単位でBAN済みのものがあり、
  1個混ぜるだけでその投稿が検索から丸ごと消える
- 大（100万件超）3 / 中（10〜100万件）6 / 小（1〜10万件）4 くらいの配分にする
- 毎回まったく同じセットを貼り続けない。3〜4個は投稿内容に合わせて入れ替える

## DMへの導線（参考アカウントの手法）

bio の「作品名分からなければDMで送ってください」は、**エンゲージメント率を人為的に上げる**仕掛け。
DMのやりとりはInstagramの評価上とても重い。ただし手動対応は現実的に破綻するので、

- よくある質問の**定型文をメモアプリに用意**しておく
- 返信は「リンクにまとめてあります → 該当のカテゴリ名」で誘導する
- 自動応答（Meta のビジネス設定にある「よくある質問」機能）を1つ設定しておく

## 投稿頻度

- 立ち上げ1ヶ月：**1日1本**を切らさない。ここでアカウントの評価が決まる
- 2ヶ月目以降：1日1〜2本 ＋ ストーリー1日2〜3枚
- ストーリーは「今日の1本」のリマインドと、リンクへの動線に使う（リンクスタンプ）
