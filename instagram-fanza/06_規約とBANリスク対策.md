# 06. 規約とBANリスク対策

## 正直な前提

**FANZA同人のアフィリエイトをInstagramでやる以上、凍結リスクはゼロにできない。**
Instagram のコミュニティガイドラインは性的な描写と成人向け商品の宣伝を禁止しており、
このアカウントは「その手前ぎりぎりを全年齢の表現で走る」構造になる。

したがって目標は「絶対に飛ばない運用」ではなく、
**飛ぶ確率を下げ、飛んでも事業が止まらない構え**を作ることになる。

## やらないこと（一発で終わる）

- 作品のサンプル画像・表紙のうち、露出のあるものをそのまま投稿する
- 性行為・性器・過度な露出の描写（モザイクや加工でごまかしたつもりでも判定される）
- 露骨な単語をキャプション・ハッシュタグ・ユーザーネームに入れる
- **未成年に見えるキャラクターを性的文脈で扱う**（Instagram・DMM双方で最も重い違反。判断に迷う作品は扱わない）
- 漫画のコマの無断転載（著作権侵害。権利者からの通報が直接来る）
- プロフィールから成人向けサイトへの直リンク
- 「DMで無料で送ります」等、無許諾配布を示唆する文言（海賊版と見なされる）

## 効く予防策

| 対策 | 理由 |
|---|---|
| 投稿に使うのは**自作テキストカードと自作イラストだけ**にする | 権利侵害の通報が構造的に発生しない |
| ハッシュタグを**毎回同じ30個**にしない | 自動化アカウント判定を避ける |
| フォロー・いいねを**1日100件以内**、時間を分散 | 短時間の大量アクションが制限のトリガー |
| コメントの非表示ワードを設定（`01` 参照） | 荒れたコメント欄は投稿単位で配信が絞られる |
| 通報されやすい表現を避けた**表現ガイドを自分用に固定**する | 判断を毎回悩まないことで事故が減る |
| 2段階認証（認証アプリ）＋リカバリーコード保管 | 乗っ取り由来の凍結が一番もったいない |

## 飛んだときのための構え

- [ ] **サブアカウントを1つ、別メール・別端末で先に作っておく**（本垢と相互フォローはしない）
- [ ] 投稿した動画・画像の**元データをすべてローカルに保存**しておく（再アップで即復旧できる）
- [ ] **X（Twitter）に同じ内容を並行投稿**する。成人向け表現の許容範囲が広く、FANZA導線との相性はInstagramより良い
- [ ] LPは**自分のドメイン**に置く（Instagramが消えてもURLと検索流入は残る）
- [ ] メールアドレス収集（LPにメルマガ・LINE登録の口を1つ）
      → プラットフォームに依存しない唯一の資産。フォロワー数より価値がある

## 凍結・制限されたときの手順

1. **すぐに新規投稿を止める**（制限中の投稿は評価をさらに下げる）
2. 設定 → アカウントの状態（アカウントステータス）で、どの投稿が違反判定されたか確認
3. 該当投稿を削除し、**異議申し立て**を出す（1回だけ。連投しない）
4. 1〜2週間は投稿頻度を半分に落とし、確実に安全な内容だけ出す
5. 30日経っても解除されない場合は、サブアカウントに移行する

## シャドウバン（表向き正常だがリーチが落ちる）の見分け方

- インサイトの「フォロワー以外へのリーチ」が数日で9割以上落ちる
- ハッシュタグ経由の流入がゼロになる
- 別アカウント（ログアウト状態）から自分の投稿がハッシュタグ検索に出ない

該当したら、**直近1週間の投稿のうち最も攻めた1本を削除**し、3〜5日投稿を止める。
これで戻ることが多い。戻らない場合はハッシュタグのセットを総入れ替えする。

## 法令面のチェック

- **景品表示法（ステマ規制）** … 広告表記は必須。`05` のD参照
- **著作権法** … 引用の要件（主従関係・出典明記・改変しない）を満たす範囲でのみ本文引用する
- **青少年保護** … 年齢確認の設置。LPに実装済み
- **DMMアフィリエイト規約** … 禁止行為（自己経由購入、虚偽表示、不正クリック）に触れない

この4つを守っている限り、最悪Instagramが飛んでも「事業としてやり直せる」状態は保てる。
