# 05. リンク導線とアフィリエイト設定

## 全体の導線

```
リール（全年齢・作品名は出さない）
   └→ プロフィールのリンク1本
        └→ 自分のLP（年齢確認 → 作品カード）      ← lp/ に実物あり
             └→ FANZA（アフィリエイトリンク）
```

ワンクッションを挟む理由は3つ。

1. Instagramのプロフィールから成人向けサイトへ直リンクしない（規約リスクを下げる）
2. **リンクは1本しか置けない**ので、複数作品をLPに束ねる必要がある
3. リンク切れ・アフィリエイトID変更のときに、Instagram側を触らず差し替えられる

## A. DMMアフィリエイトの登録

> 料率・審査基準・媒体登録の細かい規定は変わる。**最終的な可否は必ず管理画面と最新の規約で確認**すること。
> ここに書くのは手順の骨格。

- [ ] DMMアカウントを作成（Instagram用に分けた専用メールで）
- [ ] アフィリエイト（`affiliate.dmm.com` / FANZA側の窓口）に登録
- [ ] **媒体（サイト・SNS）を登録して審査を通す**
      - 登録するのは **LPのURL**。Instagramアカウントも登録できるなら併せて申請する
      - 審査時点でLPが空だと落ちやすいので、**先にLPを公開してから申請する**
- [ ] 承認後、管理画面で **アフィリエイトID（af_id）** を確認
- [ ] 成人向け（FANZA）の商品リンクを取得できるか、掲載条件（成人向けを掲載可能な媒体か）を規約で確認

### 必ず確認しておく規約項目

| 項目 | 確認すること |
|---|---|
| 掲載媒体の条件 | 成人向けリンクを貼れる媒体の要件。年齢確認の設置義務の有無 |
| SNSでの利用 | SNSに直接リンクを貼ってよいか、媒体登録が要るか |
| 素材の利用範囲 | 商品画像・バナーをどこまで加工・転載してよいか |
| 禁止行為 | 自己経由の購入、クリック誘導の偽装、虚偽の表示 |
| 成果の確定 | 承認・キャンセルの条件、支払い下限額と締め日 |

## B. リンクの形と計測

DMMのアフィリエイトリンクは、末尾のIDに**枝番**を付けて計測する形が使える。

```
https://al.dmm.co.jp/?lurl=<商品URL>&af_id=YOURID-001&ch=link_tool&ch_id=text
                                            ^^^^ ここを投稿ごとに変える
```

- `-001` … LPのカード経由
- `-002` … ストーリーのリンクスタンプ経由
- `-003` … DM返信経由

`lp/index.html` は URLの `?from=xxx` を読んで `af_id` の枝番に差し込む処理を入れてある。
リールごとに `https://あなたのLP/?from=reel012` の形でリンクを出し分ければ、
**どの投稿が売れたか**が管理画面のレポートだけで分かる。

（枝番の仕様はDMM側で変わりうるので、最初の1件が実際に計測できているか必ず実測で確認する）

## C. LPの作り方

`lp/` にそのまま動くものを置いてある。年齢確認・カテゴリ絞り込み・広告表記まで入っている。

```
lp/
├── index.html    年齢確認 + カテゴリタブ + 作品カード（編集不要）
└── works.json    ここだけ書き換えれば作品が増える
```

### 使い方

1. `lp/works.json` の `site` を自分の情報に書き換える
2. `works` 配列に作品を追加する（`postedAt` を入れておけば新しい順に自動で並ぶ）
   - `adult: true` … 年齢確認を通った人にだけ表示
   - `adult: false` … 全年齢作品。確認前でも表示される
3. 2ファイルをそのままホスティングにアップロードする

ローカル確認は次のとおり（`file://` で開くと `works.json` の読み込みがブロックされるので簡易サーバーを使う）。

```bash
cd lp && python3 -m http.server 8899
# → http://localhost:8899/ をブラウザで開く
```

年齢確認は `localStorage` に記録されるので、テストでやり直したいときは
ブラウザの開発者ツールで `localStorage.removeItem('age_ok_v1')` を実行する。

### ホスティング先の選び方

| 選択肢 | 判断 |
|---|---|
| lit.link / linktree などのプロフィールリンクサービス | **不可寄り**。成人向けリンクを規約で禁じているものが多く、そこが消えると導線が丸ごと死ぬ |
| GitHub Pages / Netlify / Vercel | 無料で手軽だが、いずれも成人向けの取り扱いに制限がある。**利用規約を読んでから**使う |
| Cloudflare Pages | 上より許容範囲は広いが、同じく規約確認は必須 |
| 国内レンタルサーバ（さくら・エックスサーバー等）＋独自ドメイン | **本命**。年数百円/月で、成人向けの扱いが明示されていて消されにくい |

**独自ドメインを取ること**を強く推す。ホスティングを乗り換えてもURLが変わらないので、
Instagram側のリンクを差し替えずに済む（プロフィールのリンク変更は頻繁にやるほど怪しまれる）。

## D. 広告であることの表示（これは義務）

2023年10月以降、日本では**広告なのに広告と分からない表示（ステルスマーケティング）は景品表示法違反**にあたる。
アフィリエイトはこれに直撃するので、次の2箇所に必ず入れる。

1. **LP** … `works.json` の `site.note`（初期値で「当ページはアフィリエイトプログラムを利用した広告を含みます。」が入っており、ページ上部と下部の2箇所に出る）
2. **Instagramのキャプション** … 「PR」「広告」「アフィリエイトを利用しています」のいずれかを、
   **「…もっと見る」で隠れない冒頭付近**に置く

「隠したほうが売れる」は短期的には事実だが、これは行政処分の対象になる話なので迷う余地はない。

## E. 計測すべき数字（週1で見る）

| 数字 | どこで見るか | 目安 |
|---|---|---|
| リーチ → プロフィールアクセス | Instagramインサイト | 2%あれば良好 |
| プロフィールアクセス → リンククリック | Instagramインサイト | 10%を切ったらbio見直し |
| LP到達 → FANZA遷移 | DMM管理画面のクリック数と突き合わせ | 30%未満ならLPの作品数・ボタン位置 |
| クリック → 成果 | DMM管理画面 | 数%。低いなら作品選びがズレている |

**一番効くのは一番下ではなく上から2番目**（bioとLPの入口）。ここは月1で書き換えて試す。
