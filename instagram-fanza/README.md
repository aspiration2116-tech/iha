# FANZA同人アフィリエイト Instagram 立ち上げキット

参考にした型: `comic.1225`（ヨルノホンヤ）のような「漫画紹介リール → 作品名はプロフィール/QR経由」アカウント。
これを **FANZA同人（DMMアフィリエイト）** の収益導線に載せ替えるための初期設定一式。

## 大前提（これを外すとアカウントが飛ぶ）

Instagram のコミュニティガイドラインは **性的な描写・成人向け商品の宣伝を禁止**している。
FANZA同人の表紙やサンプルをそのまま貼る運用は、続ければ ほぼ確実に 制限 → 凍結に至る。

したがってこのキットは次の3層構造を前提にしている。

```
[Instagram]           全年齢で成立する投稿だけ（作品名も伏せる）
      ↓ プロフィールのリンク1本
[ワンクッションLP]     18歳以上か確認 → 作品一覧（自分の管理下）
      ↓
[FANZA]               アフィリエイトリンク（成果地点）
```

Instagram に成人向け要素を一切置かず、判断と表示はすべて自分のLP側でやる。
これが「規約の範囲でやれる最大」であり、逆に言うと **Instagram に直接FANZAリンクを貼る運用はやらない**。

## ファイル

| ファイル | 中身 |
|---|---|
| `01_初期設定チェックリスト.md` | アカウント作成から公開までの手順（上から順にやればいい） |
| `02_アカウント名とプロフィール文案.md` | ユーザーネーム候補 / 表示名 / bio 3案（そのままコピペ可） |
| `03_アイコンとビジュアル.md` | アイコンの考え方・書き出し手順・ハイライトカバー |
| `04_投稿テンプレート.md` | リール構成、サムネの型、キャプション雛形、ハッシュタグ |
| `05_リンク導線とアフィリエイト設定.md` | DMMアフィリエイト登録、媒体登録、LP、計測 |
| `06_規約とBANリスク対策.md` | やっていいこと/だめなこと、凍結時の備え |
| `icons/` | アイコン3案（SVG + PNG 1080px）とプレビュー |

## 最短の進め方

1. `02` を見てユーザーネームを決め、空きを確認（`instagram.com/<希望名>` を開く → 404なら空き）
2. `01` を上から実行（アカウント作成 → プロアカ化 → 2段階認証）
3. `icons/` から1案選んでアイコンに設定、`02` の bio を貼る
4. `05` の手順でDMMアフィリエイト登録 → LP を作る → プロフィールにリンク
5. `04` のテンプレで **投稿を9本ためてから** フォロー・発信を始める（空アカウントに人は残らない）

## 収益の考え方（期待値の目安）

FANZA同人の成果報酬は概ね販売価格の数十%（料率は媒体・キャンペーンで変動するので管理画面で必ず確認する）。
同人1本の単価は数百円〜1,000円台なので、**1成果あたり数十〜数百円**。

- フォロワー1万人規模で、プロフィールリンクのクリックが1日100〜300
- LPからFANZAへの遷移が2〜3割、そこからの購入が数%

という現実的な歩留まりを置くと、月間の成果は「数千円〜数万円」レンジから始まる。
ここを大きくする効き目が強いのは順に **①LPの作り込み ②リールの本数 ③作品選び** で、フォロワー数そのものではない。
