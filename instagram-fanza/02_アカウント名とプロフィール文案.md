# 02. アカウント名とプロフィール文案

## 命名のルール

- **英数字・ドット・アンダースコアのみ**。日本語はユーザーネームに使えない
- 露骨な単語（`ero` `18kin` `r18` `hentai` など）は入れない
  → 検索面での露出が落ちるうえ、通報時に「意図的な成人向け運用」の証拠になる
- 3〜4語以内、口頭で言える長さ。ドットは1個まで（多いと業者っぽく見える）
- **決める前に `https://www.instagram.com/<希望名>/` を開いて404か確認**する。
  存在すれば埋まっている。似た名前のアカウントが既にジャンルを取っている場合は避ける

## ユーザーネーム候補

| 候補 | 読み・意味 | 相性 |
|---|---|---|
| `yoru.doujin` | 夜の同人 | A案（夜の書店）に最適 |
| `doujin.yakan` | 同人夜間 | 同上 |
| `midnight.tana` | 深夜の棚 | 同上 |
| `doujin.log` | 同人ログ | B案（レビュー）向き |
| `doujin.sommelier` | 同人ソムリエ | B案。長いが唯一性が高い |
| `dj.selection` | 同人セレクション | B案。汎用 |
| `kyouno.ippon` | 今日の一本 | C案（毎日1作） |
| `doujin.1day` | 1日1同人 | C案 |
| `tana.doujin` | 棚・同人 | 汎用。短くて呼びやすい |

※ `dj.` は DJ（音楽）と混同されるので、伸ばす気があるなら `doujin` を含む方を推す。

## 表示名（名前欄）

表示名は**検索対象**になる。ここには日本語のジャンル語を必ず入れる。

- A案：`ヨルノドウジン｜同人紹介`
- B案：`同人ソムリエ｜週7で読む人`
- C案：`今日の一本｜毎日1作紹介`

「同人」「紹介」「おすすめ」あたりは検索されるので、表示名に残す。

## bio（自己紹介文）3案

Instagram の bio は **150文字**。改行も文字数に入る。以下はすべて150字以内。

### A案：夜の書店（参考アカウントに一番近い型）

```
夜ふかし用の同人棚📚
毎日21時、ひとつだけ置いていきます
気になった作品名はプロフィールのリンクから
＿＿＿＿＿＿＿＿＿
※リンク先には年齢制限のある作品を含みます
👇 今夜の一冊
```

### B案：レビュー型（信頼で買わせる）

```
週に20冊読む人の同人セレクト📖
「ハズレを引きたくない人」向けに、当たりだけ置いてます
・毎日21時更新
・作品名はリンクからまとめて
※年齢制限のある作品を含みます
👇 一覧はこちら
```

### C案：シチュエーション特化（ニッチで濃く刺す）

```
"じれったい"だけを集めた同人棚
片想い・すれ違い・両片想いが好きな人へ
毎晩1作、静かに紹介します
※年齢制限のある作品を含みます
👇 気になったらこちら
```

### bio を書くときの原則

1. **1行目に「誰の何のためのアカウントか」**。ここでフォローするか決まる
2. **更新頻度を明記**（「毎日21時」）。継続が期待できるアカウントは残される
3. **最終行を必ずリンクへの矢印にする**。リンクは1本しかないので迷わせない
4. 「※リンク先には年齢制限のある作品を含みます」は入れる。
   ユーザーへの誠実さと、あとから「隠していた」と言われないための保険。
   `18禁` `R18` `アダルト` といった直接語は使わず、この言い回しに留めるのがバランス点

## 固定投稿（プロフィールの1枠目）

プロフィールに来た人が最初に見る3枠のうち、左上を固定にする。中身は次のどちらか。

- **「このアカウントの使い方」**：作品名の調べ方 → リンクの場所 → DMでも答えます、を3枚で
- **「殿堂入り5作」**：一番反応の良かった紹介をまとめ直したもの

固定は月1回、数字を見て入れ替える。

## ハイライト構成（4本）

| 名前 | 中身 |
|---|---|
| はじめに | アカウントの説明・作品名の探し方 |
| 今週の | 直近に紹介した作品のストーリーを溜める |
| ジャンル別 | 「じれったい系」「幼なじみ」など、棚の分類 |
| Q&A | 「作品名を教えて」への定型返し、DM対応の案内 |
