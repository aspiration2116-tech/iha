# 01. 初期設定チェックリスト

上から順に消化する。所要 2〜3時間（LP作成を除く）。

## A. 土台を分ける（最初にやる）

- [ ] **専用のGmailを新規作成**。個人用や他事業のメールと絶対に混ぜない
      → 凍結時に本アカまで巻き込まれるのを防ぐ。復旧申請にもこのメールを使う
- [ ] **電話番号**：既存のInstagramで使っていない番号を用意できるとベスト（なければメールのみで作成し、あとで2段階認証をアプリ式にする）
- [ ] パスワードは使い回さない。管理ツールに保存
- [ ] ブラウザは既存Instagramにログインしていないプロファイル／シークレットウィンドウを使う

## B. アカウント作成

- [ ] `instagram.com` から**ブラウザで**新規作成（アプリより入力項目が素直で、後述のプロアカ切替も同じ画面でできる）
- [ ] 生年月日は**成人の実年齢**を入れる。18歳未満設定だと広告・機能制限がかかり、後から変更しづらい
- [ ] ユーザーネーム：`02_アカウント名とプロフィール文案.md` の候補から。**後から変えられるが、変えるとURLが死ぬので最初に決め切る**
- [ ] 作成直後は何もせず**24時間放置**（作成即フォロー爆撃は業者判定のトリガー）

## C. アカウント設定

- [ ] **プロアカウントに切替**：設定 → アカウントの種類とツール → プロアカウントに切り替える
      - 種別：**クリエイター**（ビジネスより表示が軽く、DM整理機能が使える）
      - カテゴリ：**デジタルクリエイター**（「本」「エンタメ」系でも可。成人向けカテゴリは選ばない）
      - カテゴリのラベル表示は**オフ**でよい
- [ ] **2段階認証をオン**：設定 → アカウントセンター → パスワードとセキュリティ → 2段階認証 → **認証アプリ**（SMSより堅い）
      - リカバリーコードを控えてパスワード管理ツールに保存
- [ ] **非公開アカウントはオフ**（公開のまま。非公開だとリールが伸びない）
- [ ] **アクティビティのステータス**：オフ
- [ ] **コメント管理**：設定 → プライバシー → 非表示ワード → 「不適切な可能性のあるコメントを非表示」オン ＋ カスタムワードに露骨な単語・URL・「dm」「販売」などを登録
      → 自分の投稿のコメント欄が成人向けワードで埋まると、投稿単位で配信が絞られる
- [ ] **DMのメッセージリクエスト**：受け取る（参考アカウントと同じく「作品名はDMで」を導線に使うため）

## D. 見た目を作る

- [ ] アイコン設定（`icons/` から1案。1080×1080 PNG をアップロード）
- [ ] 名前（表示名）と bio を `02` から貼る
- [ ] **リンクを1本だけ設定**（LPのURL。`05` 参照）
- [ ] ハイライトカバー3〜5枚を用意（`03` 参照）。ストーリーを上げてからハイライト化する

## E. 公開前のストック

- [ ] **リールを9本ためてから運用開始**。プロフィールに来た人が「3列×3」で世界観を判断するため、
      1本目だけ上げて放置するとフォロー率が数分の一になる
- [ ] 最初の9本はジャンルをばらけさせる（`04` の型を9通り）。どれが刺さるかの計測を兼ねる
- [ ] 投稿は**1日1〜2本**、時間帯は 21:00 / 24:00 前後（同人・漫画系の可処分時間帯）

## F. 収益側

- [ ] DMMアフィリエイト登録・媒体登録・審査（`05` 参照）
- [ ] LP作成 → 年齢確認 → 作品カード
- [ ] 計測用の ID/パラメータ を投稿の型ごとに分ける（どの型が売れたか見るため）

## G. 30日目のレビュー

- [ ] 保存数（Save）上位3本 → その型を量産
- [ ] プロフィールアクセス → リンククリックの率が10%を切っていたら bio と固定投稿を書き換える
- [ ] LP到達 → FANZA遷移が30%を切っていたらLPのボタン位置と作品数を見直す
